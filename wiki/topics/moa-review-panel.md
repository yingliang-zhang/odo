# MoA Review Panel & Verdicts

- All three panel models emit markdown-decorated verdict lines (`**Verdict: ACCEPT**`, `## Verdict: ACCEPT`) that the bare-token `parseVerdict` never matched — 61% of accept-grade legs were misfiled as needs_fixes and the Tier-1 memory gate was structurally dead (0 applies ever) until `normalizeVerdictLine` stripped decoration to a fixpoint with a letters-free cutset, leaving fail-closed semantics unchanged by construction (bug-fix-epoch-43)
- Structured verdicts use schema-in-prompt + validator fallback because OMP has no `--output-schema` flag: parse structured-first, schema-violating JSON routes to the Infra leg (fail-closed), non-JSON falls back to the legacy text path, and comments/blockers truncation is fail-closed on all three paths (bug-fix-epoch-57)
- Consensus aggregation (>=2/3 ACCEPT) reads only the parsed `verdict` field and was deliberately left unchanged by the structured-verdict work; `comments`/`blockers` journal additively into existing rows (bug-fix-epoch-57)
- panel_mixed (2 accept / 1 reject) is terminal auto-reject under the M20 charter and `accept_diff` is hard-guarded on pending status; when dissent reasons are refuted at code level (all callsites audited), the precedent is manual land plus a `ledger_correction` journal row, leaving the store entry rejected as convention (main-epoch-27)
- One dissent does not end the chain: `panel_minority_reject` routes to a revise round per D7 policy rather than terminal rejection (bug-fix-epoch-29)
- The settle repair chain is permanently closed above the 64 KB diff cap — no silent truncation, ever — so large diffs can only land via manual Accept (main-epoch-33)
- Above a 128 KB trigger, revise prompts carry a needs-based digest — per-file stat block, full hunks of only the files non-accept feedback names, and an elision trailer pointing at the on-disk patch — with the 256 KB hard cap backstopping the digested input; worst case is conservative over-elision, never silent truncation, and files absent from the diff are never included (anti-smuggle) (bug-fix-epoch-29)
- Grounded-leg tool-loop exhaustion marks the leg Infra and parks the round blocked-pending (recoverable) instead of counting a synthesized needs_fixes as real dissent — a burned-out tool loop is not direction evidence (bug-fix-epoch-27)
- Panel findings are adjudicated against source before acting: disproven claims (unions already derived, props already stable, leaf-only Lstat on an already-escaped root) are skipped with evidence, valid ones fixed — e.g. the sameAutoDistillList duplicate-id contract hole (main-epoch-33)
