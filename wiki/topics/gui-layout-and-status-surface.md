- Guardian risk taxonomy in LedgerPanel: `review_action` rows render as receipt cells (action badge + actor Auto/Human + risk badges + timed-out chip + detail) from the existing `events` state with zero new IPC; class→severity map (credential_probe=critical through supply_chain=low); `risk-unrated` is dashed-neutral and never masquerades as clean; fixture placement matters — receipt rows in conv 1 collided with MessageBubble bubbles, so they live in conv 3 (gui-wave-epoch-1)
- Wave A "still running" visibility uses only honest data: the watch diffs the raw (not view-filtered) `runningWorkstreams` set with first-observation seeding and 4 s TTL, making jump-to-bg-run immune to false "finished"; bg rows can only say "still running" because non-focused conversations are never polled; the "Done" tier was deliberately deferred — no done-observable exists until a daemon task registry wave lands (gui-wave-epoch-1)
- Wave B honest-derivation rules: pending prompt bytes come from reverse-scanning existing journal closures (zero new IPC); the stats strip never fabricates rate — byte branch `in 1.1 MB · out 175 B`, token branch only when counts exist, with defensive `input/output_tokens` so it auto-upgrades to tok/s once the daemon journals usage; the panel popover lists verbatim receipt keys instead of inventing a per-layer byte breakdown that only exists as sha16s (gui-wave-epoch-2)
- Transparent popovers root cause: every StatusBar popover carried an inert e2e marker class `bg-runs-menu`, and twMerge treats any `bg-*` class as the background-color group — the marker won the conflict and discarded PopoverContent's opaque base (computed `rgba(0,0,0,0)` confirmed via screenshot + @layer traversal); renamed to `runs-menu` with a standing warning comment, post-fix computed style `rgb(22,26,32)` (UI-epoch-7)
- Right-sidebar close X replaced by a TopBar toggle mirroring the left-sidebar pattern (⌘J unchanged), dead `panel-close`/imports removed, e2e rewritten as an open/close round-trip; post-deploy bundle audit confirmed `runs-menu` present, `bg-runs-menu` zero residue, `toggle-panel` present (UI-epoch-7)
- Tailwind preflight `svg{display:block}` stacked the status-run spinner above its text (and broke the path-copy Check icon too) wherever the parent wasn't flex — fixed with the `inline-flex items-center gap` convention plus a `min-w-0 truncate` child so long paths still ellipsize; verified pre/post HMR by chip height collapsing 28 px → 17 px (UI-epoch-3)
