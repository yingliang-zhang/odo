# Daemon Robustness & Crash Recovery

- SIGQUIT immunity chosen over graceful-TERM-on-QUIT: srv.Wait would hang shutdown on in-flight panels up to ~24min losing advisories anyway; main.go::installSIGQUITImmunity logs and discards each delivery via signal.Notify; SIGABRT retained for deliberate dumps; smoke-verified (kill -QUIT survives, kill -TERM graceful) (bug-fix-epoch-4)
- Orphan request sweep runs first in the NewServer recovery sequence (before any boot recovery writes new expectation rows): pure field-based recognition closes all non-control user_messages lacking agent_done/agent_error with agent_error{cause:daemon_restart} so the GUI renders a failure bubble instead of hanging; steer/park//loop control rows are skipped; self-excluding on next fold → idempotent (bug-fix-epoch-4)
- 'daemon restarted while this request was in flight' resend bubbles are orphan markers stamped on in-flight requests when the daemon dies; they persist in chat history and do not indicate current failure (UI-epoch-10)
- modernc.org/sqlite WAL recovery SIGBUS (mmap crash in _walIndexRecover memcpy) recurred 2× on 08-11 and again 08-20 15:36; candidate remedies: upgrade modernc.org/sqlite or add _pragma mmap_size=0 to the connection string to disable WAL mmap — no ticket yet (UI-epoch-10) (bug-fix-epoch-4)
- Panel progress heartbeat is memory-only (panelProg map, previewEvent precedent, never journaled): fan-out registers Total, each leg (incl. failures) increments Done, last-finishing panel deletes the entry; the poll_events handshake copies the map to avoid an encode race (bug-fix-epoch-4)
