# Gate Policy & Protected Paths

- Tier-0 is exactly `gatepolicy.go` + `gate_manifest.json` — human-only, no pipeline landing path by design; Tier-1 covers control-plane prefixes, and `internal/ipc` broadly expects the full auto-land panel (bug-fix-epoch-58)
- Adding `.odo/rules.json` to the hard Tier-0 list is self-contradictory — the entry requires re-pinning a sha16 inside `gate_manifest.json`, which is itself Tier-0 — so the pipeline correctly refused diff #147 with `gate_core_path`; the revert kept Tier-0 exactly as HEAD (bug-fix-epoch-58)
- `.odo/rules.json` is project state, not control plane: its protection lives in compiled code — an `allow` rule matching a Tier-0/Tier-1 gate-source path is ignored and journaled as `rule_override_ignored`; the compiled code, not the file list, is the boundary (bug-fix-epoch-58)
- The rules overlay extends, never replaces, the hardcoded gate policy: `deny` -> needs_fixes with `rule_deny:<reason>` (Human Accept stays the unconditional escape), `ask` -> forces MoA review regardless of risk classifier, `allow` -> explicit passthrough narrowing only non-protected paths; malformed JSON -> journaled `rules_parse_error` with zero rules active; absent file -> zero rules, zero overhead (bug-fix-epoch-57)
- Rule ordering is gitignore-style last-match-wins per path, with cross-path deny dominating ask in aggregation — resolving the spec's own priority list contradicting its narrowing example (bug-fix-epoch-57)
- Rules load at auto-land start, after the gate-policy check (`autoLandCheck`) and before rebase/verify; the loop Mode A lane (own risk gate + `runVerifyGate`) is a known tightening gap, not a loosening (bug-fix-epoch-57)
- Gate-drift latch surfaces in the GUI by fold-not-push: the latest `auto_land_blocked` row with `gate_policy_drift` within the boot window renders an inline non-foldable StatusBar banner (chosen to avoid the App Esc-gate chain), with recovery copy `odo gate re-pin` + commit + restart (bug-fix-epoch-44)
- `server.go` is not a protected path (`isProtectedPath` covers autoland/autonomy/learner/review/settle/ledger/risk/contradiction/design_moa/skills_gate — the `odo rules audit` handler precedent), so changes there take the normal auto-land path (bug-fix-epoch-43)
- Diffs touching protected wiki paths are rejected whole — the invariant is agents never write memory; wiki corrections must land through the daemon's own distill/wiki-commit pipeline, never agent edits (main-epoch-42)
