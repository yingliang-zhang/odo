# Agent Worktree & Environment Conventions

- Re-apply-only doctrine: when the designated worktree no longer exists (swept), replay the archived diff verbatim from the journal — resolve the patch path from the journal, verify the diff base is an ancestor of the active worktree HEAD, git apply --3way, zero edits; a fresh clean worktree means applying the archived patch yourself (bug-fix-epoch-54)
- On re-applies, full suites are deliberately not re-run — prior evidence stands; only fast confidence gates run (bug-fix-epoch-42)
- Stage only in the agent's own worktree (sibling .odo/worktrees are read-only reference, pitfall #36), leave the tree staged-dirty with zero commits, and let the pipeline's drain stage and land (bug-fix-epoch-42)
- Worktree node_modules is provisioned by APFS clone (cp -Rc) from the main checkout — bare cp -c fails on directories, and re-cloning into an existing node_modules with plain cp -R creates node_modules/node_modules whose duplicate React causes mass false invalid-hook vitest failures (bug-fix-epoch-53)
- The Bash cwd parameter drops intermittently, silently running commands in the main checkout or wrong worktree (green gates in the wrong tree) — mitigate with explicit cd && and pwd assertions before gate runs; one stray sed polluted a line of main's server.go and was restored and verified via build + empty git status (bug-fix-epoch-53)
- The persistent shell's cwd can silently reset to the repo root, where vitest loads no config (node env, no jsdom, no setup file) — always pass an explicit cwd when running GUI gates (bug-fix-epoch-44)
- When an atomic multi-op edit fails mid-application, recover by re-reading the exact regions and re-sending; when a multi-op edit partially fails, roll back the whole op set for atomicity and re-send with smaller anchors (bug-fix-epoch-54)
- Symlinking the main checkout's node_modules into a worktree passes tsc and vitest but breaks Playwright with dual-instance beforeEach exceptions — real installs (npm ci) or APFS clones are the reliable provisioning path (bug-fix-epoch-30)
