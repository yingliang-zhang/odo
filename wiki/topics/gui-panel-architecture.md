# GUI Panel Architecture

- The contribution registry in `contrib.ts` is the single source of truth: `PanelTab` union and `PANEL_TAB_IDS` derive from it, so removing an entry lets the compiler enumerate every reference site — delete, don't shim, and migrate every caller (bug-fix-epoch-52)
- Keep-alive contract: panels mount once behind the active flag and refetch on inactive->active transition with uncommitted-draft protection; hidden panels memo on the last relevant event seq so quiet poll ticks re-render nothing (main-epoch-34)
- LRU park caps mounted ContextPanel tabs at ~3 (active + 2 MRU); editors with unsaved drafts are park-exempt; restoring a parked tab remounts and refetches (bug-fix-epoch-27)
- Strip budget is measured, never estimated: 9 tabs ~665px content vs 703px client at 720px MAX restores the no-arrow fit; e2e predicates flip only on measured truth (settle a frame before reading overflow; read CSS values in px), and the `PANEL_CONTRIBUTIONS.length <= 9` assertion recalibrates whenever a tab is added (bug-fix-epoch-52)
- One derive, many consumers: `todoItems` lifted to App feeds PlanChip, TasksPanel, and the tab badge from a single memo — removing a redundant O(journal) fold per poll tick (bug-fix-epoch-48)
- Fold, not push (established doctrine): the GUI derives every surface from journal events the poll already holds — auto-curate backoff footers, gate-drift banners, review receipts — with zero new IPC (bug-fix-epoch-53)
- Standing adoption-lock GUI conventions: typed `slots.ts` data-slot selector map (never inline selectors), a table-driven keybind registry, ordered error-summarizer rules grounded in the Rust bridge's `format!` strings, and ToolDiffView reusing DiffViewer's exported `parseFileSegments` rather than a second parser (bug-fix-epoch-26)
- ANSI rendering bypasses Markdown entirely — `renderAnsi` entity-escapes first, then trusted inner HTML, with a zero-overhead fast path on the ESC prefix — because the codebase's Markdown.tsx deliberately has no `dangerouslySetInnerHTML` (bug-fix-epoch-55)
- Daemon advisories (`payload.odo === true`) render amber and are non-terminal in `deriveRuns` — no fabricated error row for an event that corresponds to no run's failure; a group holding only an advisory shows the honest-unknown glyph (bug-fix-epoch-53)
- `write_memory` is argv-strict — only `memory.md` | `pins.md` via atomic tmp+rename; `user.md` excluded as cross-project prefs — and retry of a failed run reuses `send_message` with the original prompt recovered from the journal rather than new IPC (bug-fix-epoch-55)
- Verified GUI debt and direction: monolithic App.tsx state, full-history transcript folds, per-pointermove resize setState, and a mixed design language; the recommended order is perf fixes -> durable pages (Wiki/Memory/Skills/Ledger) vs working panes (Changes/Review) -> a single design contract (main-epoch-42)
