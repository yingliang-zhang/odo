# Design-MoA Pipeline (R-W4)

- Design-MoA runs behind prefs flag design_via: moa resolved through R-W3 resolveVia; absent, explicit omp, or garbage values all fail closed before any moa call (pinned by TestDesignMoaPrefsOff) (moa-chain-epoch-2)
- Blind legs: 3 concurrent moa.QueryWithTools calls, models from prefs review: via parseReviewModels, same goal+context prompt per leg, repo-root-scoped FS executor (newFSToolExecutorRooted extracted in fstools.go, /panel behavior unchanged), 16-round tool-loop cap, per-leg timeout via moa.TimeoutForModel (moa-chain-epoch-2)
- Truncation semantics (stricter than spec text): a truncated leg is a failed leg — partial text dropped and never fed to the consolidator, but its receipts (final escalated wire body) are kept; pipeline degrades and proceeds on surviving legs and dies only when every leg fails; a truncated consolidator fails the command closed with no design_lock row (moa-chain-epoch-2) (moa-chain-epoch-3)
- Journaling: one additive review_action{action=design_lock} carrying consolidated text + per-leg verdict metadata + per-leg request_sha16/request_bytes; failures journal memory_update{layer:design, cause:failed} with proposals (model/error/truncated/receipts) and a consolidator receipt block attached via the shared designConsolidatorReceipt helper (moa-chain-epoch-2) (moa-chain-epoch-3)
- Wire key kept as design_proposals, not the demanded proposals: Response.Proposals is already claimed by memory_proposals and encoding/json's dominant-field rule would silently drop both same-named sibling fields — minimal-fidelity deviation documented in protocol.go and pinned by TestDesignMoaResponseWireKeys (moa-chain-epoch-3)
- Fail-closed pins: context symlink escape rejected via EvalSymlinks root once + per-file lexical check + post-resolve validation (mirroring fsToolExecutor.resolve); whitespace-only consolidator lock → error + one failure marker, no design_lock line; leg labels by prefs index 'A'+i so mid-leg drops keep labels stable; concurrency single-flight via the `designing` Server field mirroring `curating` (moa-chain-epoch-3) (moa-chain-epoch-2)
