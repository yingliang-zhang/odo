# Design-MoA Pipeline (R-W4)

- Design-MoA runs behind prefs flag design_via: moa routed through resolveVia; absent, explicit omp, or garbage values all fail closed before any moa call, pinned by TestDesignMoaPrefsOff (moa-chain-epoch-2)
- Three blind concurrent moa.QueryWithTools legs use models from prefs review: via parseReviewModels, an identical goal+context prompt per leg, and a repo-root-scoped FS executor from newFSToolExecutorRooted with /panel behavior unchanged (moa-chain-epoch-2)
- A truncated leg is treated as a failed leg: its partial text is dropped and never fed to the consolidator, but its receipts are kept; the pipeline dies only when every leg fails, and a truncated consolidator fails closed with no design_lock row (moa-chain-epoch-2)
- Journaling is one additive review_action with action=design_lock carrying consolidated text plus per-leg request_sha16/request_bytes; failures journal memory_update{layer:design, cause:failed} so long passes never die silently (moa-chain-epoch-2)
- Concurrency uses a `designing` single-flight field on Server, mirroring the existing `curating` precedent, and the command is project-scoped via resolveProject (moa-chain-epoch-2)
- Wire key design_proposals was kept over the spec-literal `proposals` because Response.Proposals is already claimed by memory_proposals and encoding/json's dominant-field rule would silently drop both same-named sibling fields (moa-chain-epoch-3)
- Single-leg truncation keeps degrade-and-continue semantics: the instruction's error-demanding test point conflicted with its own constraint clause and both design docs, and the constraint won (moa-chain-epoch-3)
- Fail-closed everywhere: symlink escape in designContextBlock (EvalSymlinks the root once to avoid the macOS /var→/private/var false positive), empty consolidator lock, and receipt loss are all refusal paths, never silent degradation (moa-chain-epoch-3)
- Leg labels derive from prefs index 'A'+i so gaps persist when a mid leg drops, fixing label drift where a surviving Leg C was relabeled 'Leg B' and collided with the dropped leg (moa-chain-epoch-3)
- fail() gained an extras merge: all four failure sites (all-legs-fail, consolidator error, truncation, empty lock) now attach proposals and the consolidator receipt block to the design/failed marker via a shared designConsolidatorReceipt helper (moa-chain-epoch-3)
