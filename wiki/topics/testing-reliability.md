# Testing & Suite Reliability

- The IPC suite was structurally accelerated with zero assertion changes via one production seam (oneShotPollNs following the resolvedIdle precedent) plus t.Parallel on 44 stateless tests, while daemon-lifecycle tests (real NewServer, SQLite, sockets, t.Setenv) stay serial. (bug-fix-epoch-33)
- The serial 843s IPC suite came down to ~508s, escaping the 840–865s range that twice timed out zero-failure verify runs at the gate's 14m line. (bug-fix-epoch-34)
- WINDOW-class tests — those interleaving with a mid-flight run — must pin ODO_STUB_SCALE=1 beside their stub wrapper: at scale 0.15 the stub sleeps ~0.45s but real work (git apply plus journal) between send and first poll exceeds that window. (bug-fix-epoch-34)
- Negative-window semantics stay real: settle-family nothing-happened-before-X windows cannot be shrunk; only auto-family windows were pinned via the seam. (bug-fix-epoch-33)
- In-suite stalls are treated as real anomalies, not flakes — the Valve composite-wait stall was root-caused (parked goroutines all t.Parallel residency at zero CPU) and fixed rather than tolerated. (bug-fix-epoch-33)
- Tests pinning exact event sequences break when new defer-journaled receipts shift sequences: adjust the tests (pre-receipt prefix plus a dedicated receipt assertion) and keep the production receipt. (bug-fix-epoch-33)
- Tests must be hermetic: the one replay test without HOME isolation failed in the verify sandbox but passed on dev machines because its outcome depended on ambient ~/.odo/user.md. (bug-fix-epoch-20)
- The M20 arming gate reads review prefs from the process HOME — pipeline tests need HOME isolation plus arming or they silently zero-row exit. (main-epoch-25)
- Verify-env determinism: PLAYWRIGHT_BROWSERS_PATH is scrubbed via t.Setenv, and GOTELEMETRYDIR is pinned under TMPDIR to kill the go-telemetry async-write race that once caused a TempDir-cleanup flake. (main-epoch-26)
- Verify runs go test with a 14m timeout because go test's default 600s kills the ~535s IPC suite under daemon load. (bug-fix-epoch-16)
- A full-suite failure at exactly 600.45s was diagnosed as the default 10-minute timeout (new boot fold plus drain pushing the ~575s baseline over), not a deadlock. (main-epoch-42)
- capDetail head-trimming ate the --- FAIL lines; tail-bias truncation (rune-safe, 4KB cap, prefix marker) keeps failure names alive, and full verify output persists to .odo/verify logs with the journal pointer appended after capping so it can never be truncated away. (main-epoch-26)
- Flake adjudication doctrine: same-bytes reproduction (archive sha16 identity, payload path attribution, repeat-each runs) distinguishes collateral flakes from real regressions — a green same-bytes run means a full re-run adds zero information. (main-epoch-37)
- Full-suite reruns are skipped when judged negative-information (~coin-flip re-block risk) after same-bytes reproduction isolates the failure to an unrelated spec defect. (main-epoch-37)
- Test-harness flakes (TempDir teardown failures) are classified as flakes and re-verified, never modified in the test. (bug-fix-epoch-30)
- Deterministic spec-design flaws are fixed at the root: the dev mock evaluated the fail branch before delayMs so bootstrap rejected immediately with no window between optimistic-toggle render and rollback — fixed by moving the delay check first and pinning the window in the spec. (main-epoch-37)
- e2e assertion policy: eventually-stably-visible contracts use polling retries; poll-loop-derived assertions get the 12s window while RPC-local assertions keep the 5s default — no second convention beside the existing REFRESH family. (main-epoch-36)
- e2e specs must inject the daemon wire shape (call plus result pairs): an orphan zero-call result folds into the previous run's collapsed N-tool-calls details and affordances never become actionable. (bug-fix-epoch-28)
- display:contents elements generate no box — getBoundingClientRect is always all-zero, so intersection assertions must measure the bubble inside the anchor. (bug-fix-epoch-28)
- Assertions are never weakened: spec changes restore wire shape, fix structurally unmeasurable elements, or pin timing windows; genuine component bugs (StrictMode fetch starvation) are fixed in the component, not plumbed around in the spec. (bug-fix-epoch-28)
- Load-sensitive paths get 100x stress harnesses (two hub-managed load-generator jobs), and the harness bash cwd parameter never lands — use in-band cd. (bug-fix-epoch-37)
- Reproduce on the staged tree first before falling back to archived-patch scratch worktrees — the staged bytes are the bytes the verify gate judged. (bug-fix-epoch-37)
- The full suite must validate the exact staged bytes: a suite that finished before post-suite conflict-resolution edits validated a different tree; confirm nothing was staged after the suite started. (bug-fix-epoch-37)
- Evidence reuse over re-execution: cite prior full-suite logs when re-verifying byte-identical content and only re-run quick gates. (bug-fix-epoch-35)
- The vitest css:false stub swallows .css?raw imports to an empty string — CSS pin tests read app.css via node:fs, inject it into the jsdom CSSOM, and assert on rule declarations because jsdom does not resolve var(). (bug-fix-epoch-23)
- Radix portals escape the mounted container — palette tests must query document, not container. (bug-fix-epoch-26)
- Focus gates for timing-window tests use 3 fresh processes rather than a single -count=3 invocation, for better process isolation. (bug-fix-epoch-34)
- gofmt provenance is checked before blaming a diff: residual flags were proven pre-existing in base, closing the loop with evidence. (main-epoch-40)
- Repo-wide gofmt re-formatting is refused — the new gofmt blank-line rule flags untouched files and the project gate is build+vet only, so mass churn was declined. (main-epoch-36)
