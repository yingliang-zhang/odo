# Distill, Curate & Wiki Pipeline

- distillCore is the single funnel for memory proposals: gate + propose run before the marker, auto-apply runs after it (leaving unownedFoldGrowth untouched); wiki changes auto-commit at distill/curate end via commitWiki emitting memory_update{layer:wiki}, and the accept path's checkAndRefreshBase tolerates HEAD movement from those wiki commits on disjoint paths (main-epoch-11)
- Memory/wiki auto-gate panel-adjudicates proposals (generalized skills_gate fan-out with a rules review prompt + panelAccepts); it needs only review models and has ZERO dependency on .odo-verify, unlike the diff auto-land gate (main-epoch-12)
- Empty-window guard: a window is empty iff !unownedFoldGrowth(events, firstSeq-1), sharing the fold self-authored-line classification with the supersession probe — pure bookkeeping windows (e.g. wiki-commit telemetry) no longer trigger distills (main-epoch-11)
- Auto-distill goroutines and timer callbacks are Server-lifecycle members: distillWG Add-before-go under s.mu after the timer identity check, stopAutoDistill() bars post-shutdown arms and stops pending timers, and Wait() drains recoverWG before stopAutoDistill before distillWG, ahead of store close (bug-fix-epoch-5)
- Epoch-42 completed that lifecycle work by also wrapping auto-distill spawns into Server.wg and tracking the recoverPendingDiffs fan-out, with rig.stop draining in-flight work (3.7-3.9s blocking) — the former 'database is closed' writes after TempDir cleanup are now -race green x3 (main-epoch-42)
- Fold commits are atomic: epoch bump + fold marker land in one transaction; read paths narrow via LatestFoldBoundary probes, and no-pin legacy markers fall back to full history (firstSeq=0) so pre-pin batches stay rescuable by the sweep (main-epoch-23)
- Contradiction auto-retract was demoted to advisory-only after the 2-token-overlap heuristic mass-retracted notes (28 distills, 25 retracts, zero unretracts): candidates no longer filter recall, and retraction flows only via curator supersede or the 'odo retract <note> [reason]' CLI (main-epoch-14)
- The contradiction pass additionally skips notes already carrying a supersededBanner prefix, saving work and avoiding double-processing of curated-out notes (main-epoch-23)
- Learner auto-gate is instrumented BEFORE any threshold changes: idempotent batch_superseded journal rows, per-epoch accepted/rejected ledger lines, and a deploy-staleness WARNING when the binary mtime lags HEAD commit time by >5min (main-epoch-14)
- Curator supersede protocol: declared note names are machine-validated (must be in notesRead AND referenced by at least one written bullet), then the daemon atomically stamps a SUPERSEDED banner; banner notes stay on disk for citation liveness, are skipped by recall injection, but remain curator-readable because gen-2 topics rebuild from source notes (main-epoch-6)
- Skill-system containment: skill dir resolves through guardedBase (a symlinked .odo/skills degrades the whole scope to absent), handleDeleteSkill gained the same guardProjectWritePath as update, and skill scan enforces a 64KB per-file limit where an oversized file is skipped without blocking smaller relevant ones (main-epoch-38)
