# Loop Engine & Control-Plane Hardening

- The control-plane spine is verified healthy and is the standing invariant: pure-fold state derivation, journal-first evidence, daemon-exclusive writes, connect-vs-read retry split. (main-epoch-14)
- Gate policy is two-tier and structural: Tier-0 (gatepolicy.go, gate_manifest.json with sha16-pinned hashes; the manifest's own hash slot is empty by construction) is human-only - editing IS the exemption grant; a startup drift latch recomputes each Tier-0 sha16 and fail-closes autoLand, loopFix, and the settle majority valve with gate_policy_drift until the human-only odo gate re-pin rewrites the manifest (which never commits); Tier-0 hits by any non-human actor are hard-refused at accept time and pre-panel as gate_core_path. (bug-fix-epoch-14)
- Loop fixes that touch gate source reroute through the normal panel via s.autoLand verbatim (inherit-never-fork); the verify-only landing path for loop fixes was deleted. (bug-fix-epoch-14)
- Fold attribution is binding-gated: an accept/blocked row attributes to the open Mode A fix phase only when actor is loopActor or autoActor AND a loop_diff_bound{round} row names the diff - no binding, no attribution (fail-closed). (bug-fix-epoch-14)
- Gate-source hits never pollute the autonomy ladder (classifyDiff stays memory-prefix-only), and git.PatchPaths includes pre-image paths so a rename out of a protected prefix is gate-source on both sides. (bug-fix-epoch-14)
- Executor budget constrains measured spend, not estimates: usage is summed per-assistant-message from run JSONL transcripts (missing transcript journals usage_available:false with reason, never fabricated); budgeted spend = input + output + cache_write while cacheRead is journaled but not budgeted; a spawn's estimate stays pending until its covering loop_run_usage row lands, then the fold replaces it (newest per spawnSeq wins, idempotent; covers_spawn_seq=0 falls back to round/task matching); over-budget journals loop_budget_exceeded and suspends BEFORE autoLand; the GUI fold mirrors the rule client-side. (bug-fix-epoch-15)
- When a run is journal-terminal but the block was pure environment capacity, re-apply the archived patch onto the fixed HEAD as a fresh pipeline run rather than resurrecting the dead run. (bug-fix-epoch-16)
- Audit finding identity is structural, not wording: fingerprint v4 = sha16(norm(file) | norm(symbol) | category [| rule]) with title/evidence/expected/actual demoted to mutable description (most-severe sighting wins); per-leg fingerprint dedup precedes Legs counting (additive leg_ids aligned to journaled legs[] positions); migration is append-only - old v3 fingerprints remain historical identifiers, and boundary findings count as new for one round without arming a false stall. (bug-fix-epoch-16)
- Loop admission is atomic: state fold + loop_started journal append share one critical section (the early fold stays only as a fast-reject hint, with existing error precedence preserved), and every panel leg plus the shared reviewWithModel funnel and the /vision and /preview legs runs under an outer wall-clock deadline - previously all unbounded goroutines. (main-epoch-15)
- A single shared server-level moa client (with concurrency-cap pin tests) replaces per-call NewClientFromEnv across all call sites. (main-epoch-16)
- Verify advisory gate: one advisory per run boot when no usable .odo-verify command is committed - three-state None/Partial/Ready (an out-of-scope diff yields Partial and a scope-flavored advisory listing committed globs and suggesting a fallback line or covering glob); configured is judged from HEAD via git show HEAD:.odo-verify, never the dirty disk copy; npm test is only suggested when scripts.test is non-empty; the debounce claim-journal-release is mutex-serialized so failures never occupy the key. (main-epoch-13)
- Token estimation counts 1 token per non-ASCII rune (ASCII/4) - plain len/4 underestimates CJK about 3x and let a 110K-token prompt past the 87K breaker. (main-epoch-23)
- All new journal kinds and payload keys are additive-only (ADR-0002-immune): older folds, daemons, and the GUI ignore unknown keys safely. (bug-fix-epoch-19)
