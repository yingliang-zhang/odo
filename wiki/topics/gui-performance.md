# GUI Architecture & Performance

- Keep-alive contract: panels stay mounted (state preserved) but refetch on inactive→active transitions with uncommitted-draft protection; App passes an `active` prop into Wiki/Memory/Ledger/Skills panels (main-epoch-30, main-epoch-34)
- Render-pipeline memo is pinned to the last relevant review/memory event seq and hidden panels derive only when active — kills streaming recompute in hidden panes (main-epoch-34)
- Quiet-tick zero re-render: diffs semantic equality + ChatSurface memo + frozen props + prev-bail setters on periodic aggregates (main-epoch-30, main-epoch-32)
- Transcript windowing: `TRANSCRIPT_WINDOW_GROUPS = 25` run-group tail window in ChatSurface; render-only cut (folds, derives, and ⌘F search still read the full array); stepwise +25-groups expand chip; per-conversation expansion keyed off the live tail so streaming never re-keys; search force-reveal via seq-membership scan (runGroups provably partitions visibleEvents) (UI-epoch-12)
- rAF-throttled resize: drag buffers lastX in a ref with one `setPanelWidth` per animation frame; pointerup cancels and commits synchronously; sidebar collapse is instant geometry (no width transition relayout) plus transform-only slide using distinct collapse/expand keyframes so mid-animation re-toggle restarts (UI-epoch-12)
- Status-bar overflow lock (U1): chips never unmount — six `data-overflow-group` wrappers toggle `.sb-hidden` in a fixed hide order (ctx-meter→omp→panel→pipeline→bg-runs→count) with a higher-priority-visible recovery invariant; a single +N chip with a Radix popover builds rows from props (DOM children are not React elements, never clone DOM) (bug-fix-epoch-22)
- Poll error persistence: successful polls clear only `poll failed:`-prefixed errors; switch/send errors persist until the 10s banner timer — closes the silent switch-rollback class (main-epoch-38)
- Pipeline human lock: `derivePipelineStates.latestChainRow` must skip `auto_revise_product` bookkeeping rows, or origin diffs wedge permanently `in_flight` with Accept/Reject disabled (exclusion clause documented in pipeline-indicator-lock) (UI-epoch-10)
- Unknown memory layers fall through to the generic GUI chip (verified safe for outbox layers); MemoryPanel surfaces verdict + outcome chips from `refreshBatch` consumed-state (main-epoch-11, main-epoch-42)
- Visual coherence debt: `app.css` mixes Apple HIG radii + Multica type scale + Hermes stroke/shadow + Apple motion, and `tailwind.css` is mid-migration with legacy overrides winning; recommended order = perf → durable pages vs working panes → single design contract → 760–840px chat column (main-epoch-42)
