# GUI Performance

- Transcript windowing: TRANSCRIPT_WINDOW_GROUPS = 25 tail window as a render-only cut — fold/derive pipelines and Cmd+F search still read the full events array; a chip expands stepwise 25 groups per click, expansion state is keyed per conversation, and live runs plus the preview bubble can never be windowed out (UI-epoch-12)
- Search force-reveal uses seq-membership (events.some(e => e.seq === seq)) because runGroups provably partitions visibleEvents including the start:null preamble — immune to non-seq-ascending journal order at distill boundaries; it replaced a seq-range test that missed preamble matches (UI-epoch-12)
- Panel resize buffers pointer deltas in a ref and commits at most one setPanelWidth per animation frame, with pointerup cancelling the pending frame and committing synchronously — per-frame parity is structurally proven but real-device pointer-cadence speedup remains unmeasured (UI-epoch-12)
- Sidebar collapse animates transform:translateX + label fade only (geometry flips instantly = one relayout per toggle), using two distinct keyframes since a same-name animation cannot restart on an attribute flip; the data attr is set in useLayoutEffect so it exists at first paint (UI-epoch-12)
- Keep-alive: six right-pane panels stay mounted (state preserved), refetch on inactive-to-active transitions, protect uncommitted drafts from overwrite, and MemoryPanel deep-links use a nonce scheme to preserve initialTab semantics (main-epoch-34)
- Memoization stack: ChatSurface memo + diffs semantic equality + frozen unstable props eliminate the 350ms full-App re-render on quiet ticks; the pipeline-state memo is keyed on the last relevant review/memory event seq so hidden panels don't re-derive on every events-array replacement (main-epoch-30)
- Switch-cache: per-conversation LRU journal cache + workstream-to-conversation resolution table render instantly on click (stale-while-revalidate), bootstrap merges by seq (append-only journal makes seq-merge lossless), the daemon honors afterSeq for incremental replay, and the optimistic flip rolls back fully on switch failure (UI-epoch-8)
- Daemon-side unlock for the GUI: handlePollEvents/handlePendingCounts snapshot state under s.mu then run SQL and file I/O OUTSIDE the lock, so polls no longer serialize behind active runs (UI-epoch-8)
- Running-badge cross-talk was pure frontend: state keyed by per-journal workstream ids was not cleared on project switch — fixed via resetProjectAggregates plus a mid-flight root check, with daemon data verified correct throughout (main-epoch-6)
- Popover transparency root cause: twMerge treats any bg-* class as the background group, so the inert e2e marker class bg-runs-menu silently discarded the opaque background on all 5 StatusBar popovers — renamed to runs-menu with a keep-out comment (UI-epoch-7)
- Pipeline-lock bug: derivePipelineStates treated auto_revise_product bookkeeping rows as chain state, producing a permanent human lock; the fix skips those rows so the origin falls back to its round row (design intentionally keeps 'accept the origin to terminate the ladder early') (UI-epoch-10)
- Advisory UX invariants: panelThinking is a counter (not boolean) so concurrent advisories share the spinner; late slash rejections restore the draft only when the composer is untouched; park arm survives advisory submits via clearComposer({keepPark:true}) (bug-fix-epoch-4)
- The Tauri bridge treats an IPC write failure as terminal with no retry, preventing duplicate daemon-side execution of the same request (main-epoch-30)
- Poll error hygiene: a successful poll clears only 'poll failed:'-prefixed errors; switch/send errors persist until the 10s ERROR_BANNER_MS timer — fixing the Playwright flake class where switch failures were silently rolled back (main-epoch-38)
