# GUI Performance & UX

- Switch architecture: stale-while-revalidate per-conversation LRU journal cache with seq-based merge (append-only journal makes seq-merge lossless); incremental bootstrap via `afterSeq`; daemon SQL/file reads moved out of `s.mu` (snapshot-in-lock, I/O-outside); AGENTS.md write skipped when content identical (UI-epoch-8)
- Keep-alive panels: six panels stay mounted with activation-triggered refetch, uncommitted-draft protection, and `active` prop threading; hidden panels stop re-deriving via pipeline-state memo keyed on last relevant review/memory event seq (main-epoch-30) (main-epoch-34) (main-epoch-32)
- Full-app re-render eliminated on quiet ticks: diffs semantic equality + `memo(ChatSurface)` + frozen unstable props + prev-bail comparators on aggregate state (main-epoch-30) (main-epoch-32)
- Transcript windowing Phase 1: `TRANSCRIPT_WINDOW_GROUPS = 25` tail window in ChatSurface; render-only cut (all derive folds and ⌘F search still see the full events array); stepwise expansion +25 groups per click, never all-at-once; search force-reveals via seq-membership scan; expansion state keyed per conversation (UI-epoch-12)
- Resize: drag buffers `lastX` in a ref with one `setPanelWidth` per animation frame via rAF, pointerup commits synchronously; grip hit area fixed (z-0→z-20, painted under header before) (UI-epoch-12) (main-epoch-32)
- Sidebar collapse animates without geometry relayout: 240→48 width transition removed; `translateX` slide + label fade keyframes gated on `[data-sidebar-anim]` set in `useLayoutEffect`, with two distinct keyframe names so mid-animation re-toggle restarts (UI-epoch-12)
- Pipeline-lock bug: `derivePipelineStates.latestChainRow` treated `auto_revise_product` bookkeeping rows as state → permanent `pipelineHumanLocked` (Accept/Reject/Review disabled); fixed by skipping such rows so origins fall back to the round row's `revise` phase (UI-epoch-10)
- Popover transparency root cause: twMerge kept the e2e marker class `bg-runs-menu` over the opaque `bg-[var(--bg-elevated)]` (any `bg-*` is the background group, later wins) — `bg-`-prefixed markers must never appear in PopoverContent (UI-epoch-7)
- Slash-consult visibility: `slashing[conv] > 0` counts into `running_workstreams` (blue/purple dots, bg chip) and `PanelProgress.legs` are registered at fan-out with deep-copied poll snapshots (shallow Legs slice is a known encoding race) (main-epoch-8)
- TopBar renders `Odo · <project> · <workstream>` — the cross-project `/panel` misperception traced to a project-less TopBar plus both projects having `main` workstreams; cross-delivery was impossible (per-projectRoot sockets, fresh connection per call) (main-epoch-8) (main-epoch-7)
- Error persistence: successful polls only clear `poll failed:`-prefixed errors; switch/send errors persist until the 10s `ERROR_BANNER_MS` timer (fixes silent rollback flake class) (main-epoch-38)
- Outstanding perf/design debt: main bundle 625KB >500KB threshold, durable-pages vs working-panes IA split, single design-contract consolidation (app.css mixes four design languages), chat-column width/bubble restyle, act() warning noise — all unstarted (main-epoch-42) (UI-epoch-12) (main-epoch-32)
