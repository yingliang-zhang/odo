# GUI Architecture & Performance

- Six tenure panels are keep-alive (mounted but hidden): they refetch on the inactive→active transition with uncommitted-draft protection (App passes an `active` prop); hidden Ledger-style panels gate derivation behind activation so they don't recompute on every events-array replacement (main-epoch-34)
- Re-render discipline: memo() on heavy panels (ChatSurface pattern), semantic-equality checks on diff props froze 8 unstable props, App aggregate setState gets a prev-bail comparator, and pipeline state memos key on last relevant review/memory event seq — quiet ticks produce zero re-render (main-epoch-30)
- Transcript windowing: TRANSCRIPT_WINDOW_GROUPS = 25 run-group tail window as a render-only cut (folds/derives still read the full array, ⌘F searches over full visibleEvents), with a fold chip doing stepwise +25 expansion and per-conversation expansion state that survives workstream switches (UI-epoch-12)
- Search force-reveal uses seq-membership scan (events.some(e => e.seq === seq)) rather than seq-range comparison because runGroups provably partitions visibleEvents and the journal is not seq-ascending at distill boundaries (UI-epoch-12)
- Drag resize commits one setPanelWidth per animation frame via rAF (pointermove buffered, pointerup commits synchronously); the resize grip needed z-20 plus a 4px extended hit area because it was painted under the header at z-0 (UI-epoch-12)
- Sidebar collapse animates transform/label-fade keyframes gated on [data-sidebar-anim] set in useLayoutEffect — the 240→48px width/padding transition was deleted (geometry flips instantly, cutting chat-column relayouts 9 → 1); two distinct keyframe names because a same-name animation doesn't restart on attribute flip (UI-epoch-12)
- Pipeline human-lock bug: derivePipelineStates.latestChainRow must skip auto_revise_product rows (pure bookkeeping that is never superseded on the origin) — treating them as state permanently disabled Accept/Reject/Review even though daemon semantics say 'revise done, product self-manages' (UI-epoch-10)
- Poll error handling: a successful poll only clears poll-failed:-prefixed errors; switch/send errors persist until the 10s ERROR_BANNER_MS timer, fixing the flake class where switch failures were silently rolled back (main-epoch-38)
- panelProg is a per-consult batch-group slice: each fan-out's defer removes only its own batch and the poll snapshot merges, so concurrent panels never show Done > Total or mixed legs (main-epoch-38)
- Long-horizon GUI plan (not yet executed): transcript windowing and panel keep-alive landed as Phase 1; durable pages (Wiki/Memory/Skills/Ledger) vs working panes (Changes/Review), single design contract, and chat column 760–840px with flat agent replies remain; visual incoherence root cause is app.css mixing Apple HIG radii + Multica type scale + Hermes stroke/shadow + Apple motion with legacy tailwind overrides winning the cascade (main-epoch-42)
- Persistent debt: main bundle 625KB > 500KB warning unaddressed, and React act() warning noise in tests; slash-/preview-visibility uses display-only running_workstreams counting (no new RPC) with per-leg PanelProgress deep-copied on the poll path (shallow Legs slice = encoding race) (main-epoch-38)
