# GUI Performance & Rendering

- Transcript windowing is a run-group count tail window (TRANSCRIPT_WINDOW_GROUPS = 25) with stepwise expansion (+25 groups per fold-chip click) - a count was chosen over a byte cap for deterministic fixtures; the live run and preview bubble are never windowed out. (UI-epoch-12)
- The window cut is render-only: fold/runRenderItems/runGroups and all derive folds (loop states, pipeline states, todo, parked goals) keep reading the full events array, and Cmd-F search matches over the full visibleEvents, never the window. (UI-epoch-12)
- Expansion state is keyed per conversation with pages counting back from the live tail (streaming never re-keys, workstream switches cannot leak it, switch-back remembers it), and search force-reveal uses a seq-membership scan - runGroups provably partitions all of visibleEvents, immune to non-ascending journal order at distill boundaries. (UI-epoch-12)
- Panel resize commits one setPanelWidth per animation frame via rAF (lastX buffered in a ref, final width committed synchronously on pointerup, pending frame cancelled on unmount) - the only per-move width drag in the app; the proof is structural (<=1 commit/frame), real-device pointer cadence unmeasured. (UI-epoch-12)
- Sidebar collapse animates transform/opacity only, with two distinct keyframe names so mid-animation re-toggle restarts - never width geometry, which relayouts the transcript; distinct chat-column widths per collapse went 9 to 1. (UI-epoch-12)
- Quiet ticks render zero: diffs get semantic-equality checks, ChatSurface is memoized, and unstable props are frozen - previously the full App re-rendered every 350ms. (main-epoch-30)
- Keep-alive panels are export default memo(...) (ChatSurface pattern) and App aggregate setState gets a prev-bail comparator (reusing diff_stable) plus useCallback handlers, so quiet ticks no longer re-render. (main-epoch-32)
- Keep-alive panels refetch on the inactive-to-active transition with uncommitted-draft protection (an active prop into Wiki/Memory/Ledger/Skills), and hidden-panel memos key on the last relevant review/memory event seq instead of the events array. (main-epoch-34)
- Memory deep-link initialTab semantics survive conditional-mount keep-alive via a nonce scheme. (main-epoch-30)
- StrictMode discipline: track the fetchKey whose content has LANDED in a ref (reset on fetch rejection so re-entry retries) - tracking identity-seen starves the committed second pass into a permanent Loading state (the discarded first pass's fetch is cancelled before resolving). (bug-fix-epoch-28)
- GUI perf gate: separate vitest config; limits = ceil(measured p95 x 3) rounded up to a 10ms floor (catches order-of-magnitude regressions, not noise); violations FAIL, never warn; PERF_UPDATE=1 regenerates the baseline; contention-inflated readings (3-10x during parallel background suites) are environmental noise - quiet-rerun, never regenerate them into baseline.json. (bug-fix-epoch-30)
- ContextPanel parks all but ~3 tabs (active + 2 MRU) via an LRU state machine - Memory/Wiki editors with unsaved drafts are park-exempt; restoring a parked tab remounts and refetches per the keep-alive contract. (bug-fix-epoch-27)
- Confirmed GUI perf debt and ordering: transcript had no windowing (full-history filter/group/map per event), monolithic 2288-line App.tsx state, right-pane unmount/remount instead of keep-alive, per-pointermove resize setState, six concepts in a 380px tab strip - recommended order is perf fixes, then durable pages (Wiki/Memory/Skills/Ledger) vs working panes (Changes/Review), then a single design contract (chat column 760-840px, flat replies, fewer badges). (main-epoch-42)
- Main JS bundle is ~625KB against the 500KB warning threshold (lazy split unscheduled) and React act(...) warning noise is unaddressed. (main-epoch-38)
