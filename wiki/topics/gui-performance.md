# GUI Architecture & Performance

- Transcript windowing: `TRANSCRIPT_WINDOW_GROUPS = 25` tail window is a render-only cut — folds/derives/⌘F search keep reading the full events array; stepwise expansion (25 groups per click, never all) keyed per conversation so streaming never re-keys and switch-back remembers expansion; search force-reveals by seq-membership scan (immune to non-ascending journal order) (UI-epoch-12)
- Keep-alive tabs: panels stay mounted with state preserved, refetch on inactive→active transition with uncommitted-draft protection (`active` prop threaded into Wiki/Memory/Ledger/Skills); pipeline memo keyed on last relevant event seq so hidden panels skip re-derive (main-epoch-34)
- Quiet-tick zero-re-render baseline: diffs semantic equality + `memo(ChatSurface)` + frozen props; six panels wrapped in `export default memo(...)`; App aggregate setState uses a prev-bail comparator (main-epoch-30)
- Switch latency chain fixed end-to-end: per-conversation LRU journal cache (stale-while-revalidate, safe because journal is append-only/seq-mergeable) + `afterSeq` incremental bootstrap + daemon SQL/file I/O moved outside `s.mu` (snapshot-in-lock) + `generateAgentsMD` skips identical writes (UI-epoch-8)
- Optimistic project/workstream flip has full rollback (workstream refs, in-flight send guarding by captured cid/root) — rollback completeness was itself a review finding (UI-epoch-8)
- Panel resize: drag buffers `lastX` and commits ≤1 `setPanelWidth` per animation frame; pointerup cancels the pending frame and commits the final width synchronously; claim is structural (per-frame cadence proven), real-device pointer cadence unmeasured (UI-epoch-12)
- Sidebar animation avoids layout: width transitions removed (instant geometry flip = one relayout per toggle); motion is translateX + label fade via two distinct keyframe names (same-name animations don't restart on attribute flips); attr set in useLayoutEffect, cleared on target-guarded animationend (UI-epoch-12)
- Slash/panel visibility reuses existing channels (zero new RPC): `slashing>0` counts into `running_workstreams`; per-leg progress registered at fan-out with the poll path deep-copying the Legs slice (shallow copy = encoding race); spinner row shows per-leg ✓/✗/consulting states (main-epoch-8)
- Popover transparency bug was twMerge grouping: any `bg-*`-prefixed marker class conflicts into the background-color group and discards the opaque base class — marker classes in PopoverContent must never be `bg`-prefixed (comment left in StatusBar.tsx) (UI-epoch-7)
- Known deferred second-tier work: no single design contract (app.css mixes Apple HIG radii/Multica type/Hermes stroke/Apple motion, tailwind.css mid-migration), chat column should be 760–840px with flat agent replies, 6-tab strip consolidation, main bundle 625KB >500KB, React `act(...)` warnings (main-epoch-42)
- GUI concept/finding verification happens against real comparators (Hermes Desktop): gap list = no windowing, monolithic App.tsx state, remounting panes, per-pointermove setState — perf fixes before information architecture before design contract (main-epoch-42)
