# Memory Write Governance (D4)

- Daemon is the sole memory writer (ADR-0003 invariant 1): learner proposals wait for the panel gate; user.md waits forever for human `apply_memory`; the ADR's stale 'learner proposals wait for human' clause was amended in place (bug-fix-epoch-19)
- Scope hold before the gate: all-user.md batches are intercepted by `holdUserScopeBatch` BEFORE `applyResolvedBatch` in both auto paths — zero panel spend, journal `cause:"scope_held_for_human"`; apply-core asserts the autoActor+user.md plan is unreachable (fail-closed) (bug-fix-epoch-19)
- `memory_audit_flag` consumption is hybrid: unconsumed flags collected in `distillCore`, deduped via `cause:"flag_consumed"`, injected into the learner prompt as a verbatim DATA block (evidence, not instructions); vetting is LLM-free — a `flag:<seq>` citation must resolve to a real flag row AND a rule present in current memory.md (bug-fix-epoch-19)
- Retract intents never auto-apply: they ride the batch as `intent:"retract"` + `flag_seq`, panel-gated like any proposal; accepted ones journal `cause:"retract_candidate"`; humans resolve via `apply_memory` or `odo rules retract <text>` (bug-fix-epoch-19)
- Oscillation guard is deterministic from `memory_apply` rows: retract→re-land within 3 epochs marks the rule `[frozen]` in the prompt and rejects retract proposals `oscillation_guard` (bug-fix-epoch-19)
- Revert authority: `odo memory revert <epoch>` locates the receipt project-wide (ambiguous ⇒ refuse), verifies live bytes == receipt `after`, rebuilds the pre-image from the lane's receipt chain (fail-closed when unreconstructable), and journals `cause:"revert"`; a second revert of the same epoch is refused, as are user.md/skill-touching batches (bug-fix-epoch-19)
- Evaluate-time revert authority: `evalMemReceipt` consults the lane revert ledger before any recovery action; a reverted epoch is terminal; ledger lookup error ⇒ fail-closed no-op; suppression journaled idempotently as `cause:"revert_suppressed_recovery"` on the receipt's own lane (bug-fix-epoch-20)
- Replay fold retires reverted epochs' receipts, covering both fold-time and stale-snapshot evaluate-time windows, so boot replay cannot 'repair' reverted bytes (bug-fix-epoch-19, bug-fix-epoch-20)
- Contradiction pass is advisory-only: the old 2-token-overlap heuristic mass-retracted notes (28 distills → 25 retracts, zero `unretract` uses); it now journals `contradiction_candidate` rows that never filter recall; retraction only via curator supersede or the `odo retract`/`odo unretract` CLI pair (main-epoch-14)
- Learner instrumentation before gate changes: journal `batch_superseded` rows, ledger `memory apply: accepted/rejected` lines, and a deploy staleness WARNING when binary mtime is >5min older than git HEAD — the rule layer had silently run 30 proposals, 0 applied (main-epoch-14)
- Open: contradiction/retract candidates have no GUI surface (journal-only) and flag collection is lane-local with cross-lane propagation deferred (bug-fix-epoch-19, main-epoch-14)
