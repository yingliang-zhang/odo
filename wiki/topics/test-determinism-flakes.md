- Mock identity bug: mock-invoke passed fixture arrays by reference, so in-place e2e mutation made them Object.is-equal to React state → permanent UI staleness; mock now copies arrays at the response edge (gui-wave-epoch-1)
- Diff-8 'stuck panel' was an environmental false positive: the worktree had no gui/node_modules → `npx tsc` died in 6s; runVerifyGate now auto-provisions gui/node_modules by symlinking from the main checkout (codifying the agents' manual workaround, 3 new subcase pins) (UI-epoch-4)

- Playwright reuseExistingServer:true silently reused another worktree's stale vite build on :1420 producing false passes; recommendation to flip to false left as a user decision (bug-fix-epoch-2) (UI-epoch-2)
- WebKit-only bugs need WebKit harnesses: Chromium Playwright missed two bugs; verification stack now includes Playwright-WebKit + a native swiftc WKWebView harness (UI-epoch-2)
