# Daemon Deployment & Reliability

- Deploy rule, never violated: build from the main checkout → atomically replace (cp-to-temp + mv) at BOTH `<project>/odo` and `~/.odo/bin/odo` → THEN kill the daemon; killing first resurrects the OLD binary via `ensure_daemon_running` (main-epoch-31, main-epoch-33, main-epoch-41, UI-epoch-11)
- The mv inode swap is safe for a still-running daemon (hermes precedent); daemon-side gate fixes are inert until a restart actually loads them (main-epoch-31)
- Post-restart verification is behavioral, never pgrep alone: new PID + `go version -m` vcs.revision == HEAD in both install locations + socket answers + schema migration evidence (e.g. `schema_version=3`, `diffs.goal`) proving the new code is live (main-epoch-21, main-epoch-33, main-epoch-41)
- Stale-daemon is a recurring incident class: daemons running pre-fix binaries misjudged diffs under abolished rules (diff #36 rejected under the old one-vote veto; diff #52's heal semantics unenforced) — a deploy staleness WARNING (binary mtime >5min older than HEAD commit time) now witnesses this (main-epoch-14, main-epoch-21, main-epoch-41)
- Graceful-exit SIGKILLs in-flight agents, so the reliable restart path is a GUI full restart; a setsid-isolated resurrect+verify script was armed once but never actually ran (main-epoch-41)
- Restarting the hermes-agent daemon kills its sessions, but per-project stores are unaffected by binary swaps; both daemons run the same binary image (main-epoch-32, main-epoch-33, UI-epoch-11)
- modernc.org/sqlite SIGBUS: a recurring WAL-recovery mmap crash at daemon boot; remedy landed as DSN pragmas `mmap_size(0)` + `synchronous(FULL)` on both RW and RO opens (RO shares the live WAL) — a journaled therapy whose root cause is unproven; production recurrence remains under observation (main-epoch-15, UI-epoch-10, UI-epoch-11)
- Known CLI defect: an old binary run inside a worktree path hangs during daemon bootstrap after 'refusing to register worktree path' (`odo review list`, `odo help`); read-only journal commands still work — candidate fix unscheduled (main-epoch-27)
