# Security Guards (Paths, Symlinks, External Fetch)

- Containment doctrine: only project-side paths are constrained; global `~/.odo` files are outside the threat model (dotfiles symlinks are legitimate); `wiki/` is git-committable and in scope; escapes degrade to `vanished`/`absent` semantics rather than new error faces (main-epoch-30)
- Unified `guardProjectWritePath` (three-arg): canonical `projectRoot` is the final trust anchor, symlinks at root nodes (`.odo`, `wiki`, `wiki/topics`) themselves are rejected, and the write side carries the same guard as reads; all committable call sites migrated (main-epoch-34)
- AGENTS.md path: memory reads go through `readWithinDir` (escape → absent) and writes refuse symlinked components; `handleDeleteSkill` gained the guard the update path already had; skill dir chains resolve through `guardedBase` so a symlinked `.odo/skills` degrades project skill scope to absent (main-epoch-32) (main-epoch-38)
- Lstat-only-leaf is NOT a real bypass for `.odo` intermediate symlinks: a locally planted `.odo` symlink means journal/db/socket have all already escaped — full compromise, leaf refusal adds nothing (main-epoch-33)
- Bounded reads: `readLoopTaskFile` got `os.Stat` pre-check + anchored `readWithinDir`, later replaced with a capped reader enforcing the size limit during read (before allocation) so post-hoc length checks can't be raced by file growth (main-epoch-38) (main-epoch-42)
- Loop artifact containment: `loopArtifactBody` helper with `<field>_sha16` comparison — tampered, escaped, or symlinked `findings`/`design_lock` artifacts fail closed at both read sites (main-epoch-38)
- /preview network security: separate HEAD-precheck + GET-screenshot allowed a 204/302 bypass; fixed with an in-process loopback-only filtering proxy injected into the Playwright child plus Go-side per-hop redirect validation and final-URL capture; JS/meta-refresh redirects remain a documented v1 boundary (main-epoch-32) (main-epoch-30)
- /preview runtime pinned to lockfile `playwright@1.62.1` with an explicit setup phase instead of floating `playwright@^1` (main-epoch-34)
- Large-file preview streams via `os.Open` + `io.LimitReader(cap+1)` — never whole-file allocation before slicing (main-epoch-28)
- Skill scan enforces a 64KB per-file limit (oversized skipped entirely) and injection changed `break`→`continue` so a large skill no longer blocks smaller relevant ones (main-epoch-38)
- Risk classifier hardening: env-dump forms hit credential_probe; punctuation tokenization catches split-flag `rm -r -f` / `rm -Rf`; 87K prompt-breaker margin fixed by per-rune CJK token estimation with an 85K-pass/110K-block e2e pin (main-epoch-23)
- Explicit non-goals honored: diff `PathOnDisk` (adapter/test-generated) and user-supplied vision attachments are deliberately left unguarded (main-epoch-34)
