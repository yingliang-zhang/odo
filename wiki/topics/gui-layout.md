# GUI Layout & Interaction Design

- StatusBar overflow: chips never unmount (a hidden class keeps e2e .status-badge hooks live) with priority rank ctx-meter, OMP, panel, pipeline/running, finished/bg-runs, count chips (DOM order breaks ties) and a +N Radix popover whose rows are built reactively from props - never DOM cloning (firstElementChild is not a React element). (bug-fix-epoch-23)
- Overflow measurement requires a width-stable container: content-adaptive chip rows self-lock (hiding chips shrinks clientWidth, hiding more with no rebound) - the row became flex-1 justify-end overflow-hidden so clientWidth is a stable available-width signal; the +N chip's width must be counted in the overflow math. (bug-fix-epoch-23)
- A hidden group may only recover when every higher-priority group is visible - prefix invariant of the lock order. (bug-fix-epoch-22)
- Hidden state uses a dedicated chip-hidden token plus classList.contains and data-chip addressing - never className.includes(hidden), which also matches overflow-hidden. (bug-fix-epoch-24)
- Type tokens replace literals: --text-nano: 10px registered in :root and tailwind.css @theme; the global .truncate cap was deleted in favor of explicit max-w-[220px] on slash/mention rows. (bug-fix-epoch-23)
- Focus contract: the outline kill is scoped to .chat-input textarea:focus only; focus-within border uses color-mix(accent 55%, transparent); ModelPill gets focus-visible:ring-2 via CVA with Enter/Space keydown. (bug-fix-epoch-23)
- Panel overlay: hysteresis evaluates docked-equivalent width (chatWidth minus panel.offsetWidth while overlayed) because making the panel fixed widens chat ~420px and a naive read flips back to docked forever; a callback ref (element in useState) replaces one-shot useRef effects (booted early-return renders no main element); offsetWidth not clientWidth (Chromium border-box excludes the 1px border, off-by-one in drag max); empty/unparseable stored width falls back to default (Number(empty)===0 clamps to 280); scrim is literally click-through (pointer-events-none) with close via existing Cmd-J/Esc paths; 72ch prose cap. (bug-fix-epoch-25)
- Theme cascade is three-layer: 63 --p-* primitives, semantic tokens re-pointed, then light overrides as pure var() - equivalence proven by 42-point CSSOM var-hop resolution with 0 mismatches. (bug-fix-epoch-30)
- All new interactive elements use the slots.ts typed SLOT map plus data-slot attributes (never inline selectors); keybinds are table-driven (keybinds.ts, matchKeyEvent, allowedInInput) with a read-only ShortcutsPanel and Esc rows display-only (the Esc ladder stays imperative); Cmd-K journal search reuses the existing handleSwitchWorkstream path for foreign-workstream switches rather than inventing switch semantics. (bug-fix-epoch-26)
- Tool-result inline diffs are gated by looksLikeUnifiedDiff and reuse DiffViewer's exported parseFileSegments - no second parser, zero new IPC, read-only. (bug-fix-epoch-26)
- Error summarizer: ordered pattern-to-summary/action rules grounded in the Rust bridge's format strings (restart-failed precedes generic connect); classified errors are sticky with x-dismiss only, unclassified keep legacy auto-dismiss, toasts unchanged; poll-recovery self-heal intentionally beats stickiness. (bug-fix-epoch-26)
- ESC handling is a priority registry (overlay > menu > panel > global-cancel) with identity-based disposers, a stable-slot hook, and a test reset seam - replacing App's global querySelector chain. (bug-fix-epoch-30)
- twMerge trap: a bare token conflicts with tier color classes inside cn() - escape as text-[length:var(--text-micro)]. (bug-fix-epoch-22)
- After @types/node landed, bare setTimeout resolves to NodeJS.Timeout - window.setTimeout (DOM number) is the minimal fix for useRef<number|null>, and reverting reproduces TS2322. (bug-fix-epoch-24)
- The panel chip stays a single Panel xN - per-model expansion was invented out-of-contract and is pinned against by e2e. (bug-fix-epoch-22)
- PANEL_CONTRIBUTIONS is the single source for panel ids/titles/icons/badge derivation (PanelTab union and PANEL_TAB_IDS derived from the table); the spec's component field was deliberately omitted as inert metadata under keep-alive/LRU wrapping, with the body seam documented in contrib.ts. (bug-fix-epoch-30)
- Failure surfaces are a typed taxonomy keyed by classification (socket closed / heartbeat timeout / version mismatch / verify infra / panel infra), extending the errors.ts summarizer map rather than forking it; the P2 adoption bundle (preview three-tier, Runs journal-fold tab, failure overlay, LRU park) is built on the slots.ts data-slot contract. (bug-fix-epoch-27)
- Failure overlay contract: classified failures render title, one-line cause, and a leading action (Reconnect / Copy diagnostics / Open journal) with a reload affordance appearing once pollFailures >= POLL_FAIL_RESTART_THRESHOLD (20); focusSeq is cleared on jump-land and on conversation/workstream switch (it previously survived forever and pinned arbitrary groups into the render window on seq collision); dismissals are keyed by failure class (a different class re-arms) and reset on reconnect. (bug-fix-epoch-29)
- Successful polls clear only poll-failed-prefixed errors; switch/send errors persist until the 10s ERROR_BANNER_MS timer - fixing the class where switch failures were silently rolled back. (main-epoch-38)
