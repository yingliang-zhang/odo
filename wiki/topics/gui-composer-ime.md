- Stuck-blue input box root cause: on WKWebView the Enter confirming an IME candidate can arrive without isComposing/keyCode 229 → submit fires mid-composition → compositionend never arrives → composingRef stuck true blocks all future value-sync writes; fix synchronously clears ta.value and composingRef=false on successful send (all paths converge in submitDraft) (UI-epoch-4)
- React 19 ignores input events during composition: the controlled composer overwrote steering text with stale draft on poll/heartbeat rerenders, destroying active IME composition; composer now uncontrolled (defaultValue) with orchestrated writes in a layout effect gated on !composing, compositionend syncing via handleDraftChangeValue (UI-epoch-2)
- Composer initial-height bug: WebKit counts a wrapped placeholder into scrollHeight (Chromium does not); fix clears the placeholder during measurement (same-frame restore) + width-gated ResizeObserver re-size (UI-epoch-2)
- /panel runs synchronously inside the send_message RPC (wg.Wait over N parallel legs, can take minutes); holding sending=true across await locked EVERY workstream composer; fix = advisory slash submits detach from the composer await — box clears/unlocks immediately, spinner driven by background promise, draft restored on instant daemon rejection (bug-fix-epoch-3)
- Concurrency consequence accepted: users can now send normal messages while a panel consult is in flight (previously impossible) — safe because panel is read-only, advisory answers carry the panel flag (excluded from fold/replay), and the slashing slot only rejects distill (bug-fix-epoch-3)
- Late advisory rejection must not clobber a newer draft: submitDraft restores draft/attachments/slashToken only when the composer is untouched (textarea empty + no live attachments), otherwise keeps user content and shows only the error banner; clearComposer({keepPark:true}) preserves the one-shot park arm; panelThinking is a counter, not a boolean, so concurrent advisories share the spinner (bug-fix-epoch-4)
- Daemon/GUI advisory routing whitespace parity: daemon uses strings.HasPrefix(rest, " ") — literal space only; /panel-newline, tab, and '/ panel' fall through on both sides; parity locked with 17 daemon-mirror unit cases (was a verified-correct-but-unpinned property, now pinned) (bug-fix-epoch-4)
- Transparent-popover root cause: the inert e2e marker class bg-runs-menu collided with tailwind-merge's bg-* group (later wins) and discarded the opaque background from PopoverContent — hit all 5 StatusBar popovers; fix renamed marker to runs-menu + comment warning: never use bg-*-prefixed marker classes in PopoverContent (UI-epoch-7)
- Advisory submit no longer sets agentRunning (sibling bug): it briefly flipped the composer into steer mode + Stop button until the next poll (bug-fix-epoch-3)
