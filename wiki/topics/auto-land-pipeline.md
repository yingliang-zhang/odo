# Auto-Land Pipeline & Diff Governance

- Memory-path diffs (.odo/, wiki/) are fail-fast rejected at diff registration; the accept-layer backstop refuses them for every actor including a human Accept — wiki/memory content must land through the daemon's own distill/commitWiki pipeline, never an agent diff (invariant: agents never write memory) (main-epoch-24)
- A run whose diff touched protected path wiki/topics/memory-distill.md was rejected wholesale; the fix is to strip the wiki hunks and resend the Go/GUI work through the pipeline (main-epoch-42)
- Supply-chain paths (manifests/lockfiles/CI workflows) stay hard-blocked pre-panel: a one-line lockfile dependency change is an RCE vector that diff review structurally cannot judge (main-epoch-24)
- Blocked states other than panel_infra are terminal (the daemon never retries); manual Accept is the only unlock — applied for diffs #41, 42, 45, 46, 48, 49, 51/52 (main-epoch-41)
- panel_infra is the only non-terminal block reason; its designed resolution is restart re-fire via recover-pending-diffs (main-epoch-17)
- The repair ladder has a hard 64KB diff cap (no silent truncation, ever); diffs above the cap can never enter repair, so manual Accept is the only unlock at that size (main-epoch-33)
- .odo/diffs/ is an append-only archive, not a live queue — accepted and rejected patches are retained permanently and are sweeper-exempt (main-epoch-22)
- Rejecting a diff deletes its candidate worktree; rescueResolvedWorktree snapshots the current delta to .odo/diffs/<run>-rescue.diff pre-retirement only when it differs from the archived patch, so the reviewed patch bytes are never rewritten (main-epoch-36)
- Pipeline hazard learned on diff #47: rejecting after the worktree holds the only copy of a fix leaves the .diff archive as sole survivor; recovery = dry-check backup, git apply, re-run tests (main-epoch-35)
- Regenerating a patch file before accept is safe only when the diff never reached the panel (no patch_sha16 attestation binding); a stale patch bound to a reached panel may not be rewritten (main-epoch-22)
- Accept-path dirty-path guards: handleDiffAction refuses when patch-own paths carry staged/unstaged/untracked user content (git rollback would destroy uncommitted changes); the identical-content ProbeAlreadyLanded rescue is ordered before the dirty refusal (main-epoch-28)
- Refusal on dirty paths is deliberately NOT wrapped as errBaseStale — wrapping would trigger the auto-revise loop and burn ~8.5 min of verify per round regenerating a patch that hits the same refusal; user dirt requires human triage (main-epoch-28)
- Staged-only edits are refused via git.IndexEditsBeyondHEAD (real index vs HEAD stage-0 compare) before adjudication reuses the refusal-message family; diff stays pending (main-epoch-32)
- alreadyLanded per-file detection builds a post-image via a temp index and byte-compares against worktree hash-object; whole-file CommitPaths would otherwise absorb stray edits (main-epoch-30)
- Externally-landed zombie diffs (manual commit + ff merge) can be settled via one BEGIN IMMEDIATE transaction: UPDATE diffs status=accepted plus a review_action row with extra note keys (ignored by consumers per ADR-0002) (main-epoch-8)
- M20 auto-land root fix: reverse-apply probe in checkAndRefreshBase — git apply --reverse --check succeeds iff the post-image is already in main → settle already_landed instead of leaving a pending zombie (main-epoch-8)
- M20: reject auto-land military policy flipped default to armed (auto_apply: main); GUI accept/reject kept only as triage/override valve; policy blocks (protected_path/supply_chain/verify/infra) stay pending as anomalies requiring humans (main-epoch-8)
- Diffs store their goal at creation time (schema v3 diffs.goal column); recoverPendingDiffs, review_diff, loop seed, and revise all anchor on the stored goal rather than re-scanning the session's latest human message — fixes the false 'objective mismatch' panel rejection that wrongly killed diff #34 (main-epoch-18)
- Superseded diffs (51 by 52, 33 by 34, 21 by 22, 23 by 24) should be rejected promptly because recover-pending-diffs would otherwise re-fire their panels on every restart, racing the superset diff; archives make rejection safe (main-epoch-41)
- Recover-pending-diffs dedups: diffs with terminal verdict rows (auto_land_blocked≠panel_infra, auto_panel moa_review, auto_revise_round) are skipped; only genuinely stranded diffs (auto_land_started/refresh_attempted breadcrumbs, panel_infra, human-only review) re-fire; journal read failure fails closed and abandons the whole recovery pass (UI-epoch-9)
