# Auto-Land Pipeline & Review Governance

- Gate-source diffs can never land via the majority valve: review rounds 1-2 require unanimous accept, only the terminal round 3 lands via the majority valve (its only reachable composition is 2 accept : 1 needs_fixes), any reject leg auto-rejects fail-closed, and a truncated leg invalidates the valve. (main-epoch-21)
- Diverged verdicts (including panel_mixed) enter the repair ladder instead of instant auto-reject; if divergence persists past the round cap, a strict majority (>1/2 accepts) decides landing vs rejection, else suspend for human review. (main-epoch-19)
- Settlement classes split by model family: only >=2 reject legs from >=2 distinct families auto-reject (reject_independent); exactly one reject, or all rejects same-family, suspends as panel_minority_reject with a journal-derived repanel_count that fails closed to parked below 2 bounded restart re-fires; single-family panels have zero auto-reject capacity. (bug-fix-epoch-17)
- Model family = lowercase basename prefix before the first '-' of the bare model id (provider tag stripped, pure LLM-free function): the same model under two provider labels is the same family, so label diversity is not model diversity. (bug-fix-epoch-21)
- The D6 design-MoA auto gate admits only >=2 successful legs from >=2 distinct model families, computed over the good set only, with receipts recording the scrubbed shared endpoint rather than pretending leg endpoints differ; refusal journals auto_gate:refused_diversity, never spawns, and leaves the design lock pending for the human gate, while the manual path still locks on a single leg with diversity journaled for visibility only. (bug-fix-epoch-21)
- Any blocked reason other than panel_infra is terminal (no replay, no re-review): manual GUI Accept (accept_diff IPC; there is no CLI accept subcommand) is the only unlock, with precedent for stale-sha blocks, oversize repair-chain bodies the cap refuses to truncate, and superseded diffs. (main-epoch-33)
- Reject a superseded diff before accepting its superset - recover-pending-diffs re-fires pending diffs at daemon restart and would otherwise race the survivor (two panels were already burned this way). (main-epoch-41)
- Review objective anchors on diffs.goal stored at diff creation (schema v3; revise-chain products inherit the chain head's goal byte-exact) - never the session's latest human message, which let an unrelated connectivity note mis-kill diff #34. (main-epoch-18)
- Ledger divergence is reconciled by appending journal ledger_correction rows (corrects_seq), never silent DB mutation - store states stay as-recorded even after a manual land. (main-epoch-19)
- With exactly one review model configured the panel is not armed: a once-per-daemon-lifetime single_judge_panel advisory fires and the diff stays pending. (main-epoch-15)
- Verify failures are implementation evidence in the blocked+revise lane - never an auto-reject verdict and never a verify-reject path. (bug-fix-epoch-17)
- Tool-loop exhaustion marks a grounded leg Infra regardless of posture; panelInfraLeg parks the round blocked-pending (recoverable) instead of counting a synthesized needs_fixes as real dissent. (bug-fix-epoch-27)
- Exactly one repo-grounded reviewer leg per fan-out, weighing identically to every other leg: model-visible iff journaled (every read attempt, allowed or denied, appended before the tool output returns, so citing-without-calling is test-detectable); scope is the LLM-free one-hop import neighborhood (touched paths, same-dir Go siblings, repo files importing touched packages, repo-internal imports), degrading to touched-only with journaled scope_truncated; per-read 64KB and 256KB total-bytes caps; budget exhaustion still owes a verdict; empty scope is legal (all reads refused), not infra; a degraded grounded leg on a gate-source diff fails closed; ungrounded legs keep byte-identical prompts. (bug-fix-epoch-18)
- Panel consolidation is rejected on principle: divergent leg output is the product - a complete-looking synthesis deceives more than raw legs; the only acceptable future form is a lazy merge over journaled answers (additive agent_text{panel_merge}), never an inline consolidator in the fan-out path. (main-epoch-14)
- Panel dissents are triaged against source before acting: valid contract holes get fixes plus pins; claims refuted by existing code (already-stable props via useMemo/useCallback/prev-bail, unreachable paths, already-escaped state) are rejected with evidence. (main-epoch-33)
- Panel findings that are coverage gaps get test pins, not code changes (conservative over-elision is the sanctioned direction); Go signature ripples are compile-backed, so a full green suite rules out unmigrated callers. (bug-fix-epoch-30)
- A patch may be regenerated pre-accept per drain semantics (git add -A && git diff --cached HEAD) only when the diff never reached the panel - once patch_sha16 attestation exists, regenerating breaks the reviewed-bytes binding. (main-epoch-22)
- Panel misjudgments can be environmental: when the reviewed diff is absent from the evaluation worktree (clean tree), re-apply the archived bytes verbatim and re-verify before treating the verdict as content-based. (bug-fix-epoch-22)
- Revise runs declare their own canonical worktree at the top of both ladder prompts; a clean-and-empty revise drain journals revise_product_missing plus a recovery advisory instead of wedging pending forever, and the false-stop retry must propagate originDiffID so a repeat clean-empty also surfaces. (bug-fix-epoch-13)
- Above the 128KB trigger, settle revise prompts carry a needs-based digest: per-file stat block, full hunks of only dissent-named files, and an explicit elision trailer pointing at diff.PathOnDisk (worst case is conservative over-elision, never silent truncation; the 256KB cap stays as backstop on digested input, comments stay 16KB, and patchSHA/commentsSHA still hash the full diff so chain identity is unaffected); the named-file set = validated patch paths intersected with feedback path-tokens (boundary- and quote-aware), and files absent from the diff are never included - anti-smuggle. (bug-fix-epoch-29)
- Memory-path diffs (wiki/, .odo/) are refused at registration time using the same SSOT predicate as the accept-time backstop: wiki is the daemon's own distill/commitWiki content area, so an agent diff carrying a wiki hunk can never land - a run whose diff touches a protected wiki topic is rejected wholesale (strip the hunks and resend the remaining work). (main-epoch-24)
- Agents never edit wiki wording even to fix documented drift - wiki is protected and daemon-owned; corrections wait for the daemon's own distill/curate cycle. (main-epoch-14)
- Accept/reject recommendations are evidence-gated before answering: archive sha16 integrity, payload attribution (zero overlapping paths), same-bytes reproduction, and gate-source compliance (touching gate files makes manual Accept the legitimate unanimous-attestation bypass). (main-epoch-37)
