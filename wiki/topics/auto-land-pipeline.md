# Auto-Land Pipeline & Diff Governance

- Divergent panel verdicts (including panel_mixed) enter the repair ladder instead of instant auto-reject; at the round cap a strict majority (>½ accepts) lands the diff, otherwise it suspends for human review. (main-epoch-19)
- The settle ladder runs three total review rounds: rounds 1–2 require unanimous accept with fail-closed auto-reject on any reject, and round 3 (terminal) passes on the majority valve whose only reachable composition is 2 accept plus 1 needs_fixes. (main-epoch-21)
- Exactly one reject leg — or 2+ same-family rejects — suspends via panel_minority_reject with the diff left pending; only 2+ rejects from 2+ distinct model families auto-reject as reject_independent. (bug-fix-epoch-17)
- Minority-reject blocks are non-terminal while repanel_count < 2 (a daemon restart re-fires the pipeline once with a fresh panel); at 2+ they park human-only, and the journal-derived counter fails closed to parked on read error. (bug-fix-epoch-17)
- panel_infra is the only non-terminal blocked reason and its designed resolution is the daemon-restart re-fire; all other blocked states (verify_failed, protected_path) are terminal and never auto-retried. (main-epoch-17)
- Blocked diffs larger than the 64KB hard repair cap can never enter the repair chain — manual Accept is structurally the only landing path at that size. (main-epoch-33)
- A verify block bound to a stale sha (patch repacked after the block) never auto-retries — terminal-state diffs require manual GUI Accept as the only unlock. (main-epoch-41)
- Gate-source diffs (settle.go, autoland.go, grounded.go, loop_audit.go) require unanimous panel attestation, which a manual GUI Accept legitimately bypasses per doctrine. (main-epoch-24)
- When a superseding diff is a strict superset, reject the superseded one before accepting the replacement — otherwise recover-pending-diffs re-fires the stale diff on every daemon restart, racing its successor. (main-epoch-41)
- Diffs touching .odo/ or wiki/ are rejected at registration (fail-fast guard between ExtractDiff and InsertDiff) because wiki/ is the daemon's own content area written via distill/commitWiki — an agent diff carrying a wiki hunk is misrouted content that can never land through the diff channel. (main-epoch-24)
- The accept-time backstop refuses memory paths for every actor including a human Accept click — the agents-never-write-memory invariant holds at both the pre-panel and accept layers. (main-epoch-24)
- Supply-chain paths (lockfiles, package manifests, CI workflows) stay hard-blocked: a one-line lockfile dependency change is an RCE vector that diff review structurally cannot judge. (main-epoch-24)
- Rejecting a diff deletes its candidate worktree, leaving the archived .diff as the only copy — discovered the hard way recovering diff #47 from its backup. (main-epoch-35)
- rescueResolvedWorktree snapshots the worktree delta before retirement and writes a rescue diff only when it differs from the archived patch; the reviewed patch bytes are never rewritten. (main-epoch-36)
- .odo/diffs/ is an append-only, sweeper-exempt archive rather than a live queue — rejected and accepted patches are retained permanently and serve as the recovery source for lost worktrees. (main-epoch-22)
- Patch bytes may be regenerated per drain semantics (git diff --cached HEAD) before accept only when the diff never reached the panel, so no patch_sha16 attestation binding is broken. (main-epoch-22)
- Review prompts must anchor on the diff's stored goal (schema v3 goal column written at InsertDiff), never the session's latest human message; recover, review_diff, loop-seed, and revise all consume the stored goal. (main-epoch-18)
- All accept paths (autoland x2, settle, loop_run, manual IPC) funnel through handleDiffAction — no staged-gate bypass exists. (main-epoch-33)
- Ledger divergences are reconciled by appending journal correction records (corrects_seq), never by silent DB mutation; the store's verdict state is deliberately left as-is. (main-epoch-19)
- Manual land beats a re-run when a same-bytes reproduction is green: the re-run has zero information gain and re-exposes panel-fabrication risk (a fabricated reject once turned a landable diff terminal). (main-epoch-27)
- Over-threshold (>128KB) revise prompts carry a needs-based digest (per-file stat block, full hunks of feedback-named files, an elision trailer pointing at the on-disk patch) instead of chasing caps upward; the 256KB hard cap backstops the digested input while patch/comments SHA identity is still computed from the full diff. (bug-fix-epoch-29)
- The digest's named-file set is PatchPathsText-validated paths intersected with feedback path tokens — files absent from the diff are never included (anti-smuggle), so the worst case of a bad selection is conservative over-elision, never silent truncation. (bug-fix-epoch-29)
- recoverPendingDiffs excludes loop-owned seeds so restart recovery cannot re-fire loop runs. (main-epoch-16)
- Staged changes touching protected gate files land via the human Accept queue — expected, not avoided. (bug-fix-epoch-38)
