# Auto-Land Pipeline & Landing Discipline

- Terminal verify_failed blocks are unlocked by manual Accept only after a byte-level evidence chain (archive sha16 recompute, payload path attribution, same-bytes green re-run) proves the failure environmental — re-verifying identical bytes has zero information gain (main-epoch-29)
- Flake-rejected patches are re-applied verbatim from the .odo/diffs journal archive via git apply --3way with zero edits and fast gates only (build, git diff --cached --check, status) — prior full-suite evidence stands and the patch is never re-derived or re-litigated (bug-fix-epoch-53)
- .odo-verify's vitest segment runs --maxWorkers=2 (CLI-only, vitest.config.ts untouched so dev/test stay fast) with explicitly no --retry because retries would mask real flakes; this closes the tauri-build+playwright concurrency timeout class (bug-fix-epoch-53)
- git apply --3way records renames directly into the index, pre-staging the deletion, so remembered patch paths can exist in neither worktree nor index; StageExistingPaths filters ghost paths while keeping the patch-path-union scope — unscoped git add -A in the main checkout is P0-forbidden because it would sweep unrelated user changes, and the M20 already-landed branch was wired to the same filter (bug-fix-epoch-53)
- Locate pipeline failures by journal ground truth, not the task brief's framing: the #138 staging failure was accept-time staging in git.ApplyDiff, not drain extraction (already git add -A + rename-aware); a hypothesized M20 rename-loss gap was self-refuted and disclosed, its new tests kept as characterization pins (bug-fix-epoch-53)
- Full verify output persists to .odo/verify/<label>-<ts>.log (1MB tail cap per file, pruned to newest 32) with the journal pointer appended after capping so it can never be truncated away (main-epoch-36)
- capDetail truncation is tail-biased (rune-safe 4KB cut with an earlier-truncated prefix) so --- FAIL lines survive in journal blocked details — the old head-trim ate them and forced blind reproductions (main-epoch-26)
- Reject deletes the candidate worktree, so pre-retirement rescue snapshots the surviving delta into .odo/diffs/<run>-rescue.diff only when it differs from the archived patch; the sweeper exemption for .odo/diffs guarantees survival (main-epoch-35)
- Memory-path doctrine: diffs touching .odo/ or wiki/ are rejected at registration (agents never write memory) with a transcript advisory pointing to the distill/commitWiki route and the salvage patch kept; wiki content lands through the daemon's own pipeline, never an agent diff (main-epoch-24)
- The TestAutoLandVerifyNoEvidence TempDir-teardown flake (pitfall #42 class) can block pure docs diffs and remains unfixed — it rejected the two-.md diff #130, which cannot affect Go tests (bug-fix-epoch-47)
- Stage-drain contract: work is left staged-dirty with zero commits in the agent's own worktree and the daemon's drainRun (git add -A -> ExtractDiff -> InsertDiff) creates the diff row; an auto_panel accept (e.g. seq 22194) is not itself proof the land/merge happened — confirm against the journal (bug-fix-epoch-54)
