# Auto-Land Pipeline & Diff Governance

- Blocked states (`auto_land_blocked{verify_failed}`, panel verdicts, `protected_path`, `supply_chain_path`) are terminal for a diff — the daemon never retries; manual GUI Accept/Reject is the only unlock (main-epoch-22, main-epoch-26, main-epoch-40)
- `panel_infra` is the only non-terminal blocked reason; its designed resolution is daemon restart re-firing `recover-pending-diffs` (main-epoch-17)
- Order terminal verdicts: reject the superseded diff before accepting its successor, so a restart cannot re-fire a panel for the old one (main-epoch-41)
- Diffs touching `wiki/` or `.odo/` are refused at registration (`drainRun` guard before `InsertDiff`, reusing `rejectMemoryPaths` as SSOT) with an advisory routing the content through distill/`commitWiki`; unparseable patches pass through to the accept-time backstop (main-epoch-24)
- Memory-path refusal applies to every actor including human Accept (invariant: agents never write memory); supply-chain manifests/lockfiles stay hard-blocked because diff review structurally cannot judge a one-line lockfile RCE (main-epoch-24)
- Gate-source diffs require unanimous panel attestation; the majority valve has zero attestation power, and human Accept is the designed bypass (`TestHumanAcceptGateSourceAllowed`) (main-epoch-14, main-epoch-22, main-epoch-41)
- Same-bytes-green standard: re-run the exact archived patch bytes; if green, manual accept beats a full verify+panel rerun with zero information gain (precedents #42, #48, #49) (main-epoch-29, main-epoch-35, main-epoch-36, main-epoch-37)
- Before any manual accept, verify archive integrity: recompute sha16 of the `.diff` on disk and compare against journal started/blocked rows — archive swaps must be excluded first (main-epoch-35, main-epoch-36, main-epoch-37, main-epoch-41)
- Patch regeneration per drain semantics (`git add -A && git diff --cached HEAD`) before accept is legal only while no panel attestation is bound to `patch_sha16` (main-epoch-22, main-epoch-31, main-epoch-33)
- Stale-test fixes discovered mid-pipeline fold into the next pending diff's snapshot rather than a separate hotfix diff — byte-identical outcome, one review round-trip saved (main-epoch-10)
- The repair chain is permanently closed when a diff body exceeds the 64KB cap (`settle.go`, 'no silent truncation, ever'); manual Accept is the only unlock at that size (main-epoch-33)
- Detached-worktree commits can orphan: epoch-18's 'landed' commits never reached main because they sat on a deleted session worktree; recovery = cherry-pick orphans + journal correction (main-epoch-20)
- Ledger divergence is reconciled by journaled `ledger_correction` records (`corrects_seq` chain, store state left untouched), never silent DB mutation (main-epoch-19, main-epoch-20, main-epoch-27)
- Open loop: a full patch was rejected at registration for touching protected `wiki/topics/memory-distill.md`; strip the wiki hunks (including the stale 'delete race accepted' claim) and resend the remaining Go/GUI work — preserved patch at `.odo/diffs/6a8d8993-…diff` (main-epoch-42)
