# MoA Client Resilience & Wire Receipts

- R-W1: bounded retry in internal/moa/client.go — max 3 attempts, 200ms×2ⁿ with ±50% jitter (math/rand/v2), Retry-After honored capped at 30s; retryable = 429/≥5xx/network/timeout; typed errors Error{Status,Class,Message,RetryAfter} with five classes; no retry on caller cancel, preserving errors.Is(context.Canceled) (moa-chain-epoch-1)
- Result ledger adds InputTokens/StopReason/WallSeconds/TokPerSec: token fields record the final request, wall time covers the whole logical call (retries + escalations); tool-loop Result deliberately drops Thinking to preserve /panel behavior (moa-chain-epoch-1)
- R-W1.5 receipt semantics = final-request convention: request_sha16/request_bytes computed by the moa client at post()'s marshal point (only location seeing wire bytes); retry chain resends byte-identical body → one receipt; budget escalation rebuilds body → receipt points to the final request; error returns carry no receipt — consistent with the patch_sha16-absence precedent (daemon-misc-epoch-2) (daemon-misc-epoch-1)
- Premise correction: the R-W1.5 task claimed receipts already existed on Result from R-W1 — git show + grep disproved it, so client-side wiring was built in full; sha16 exists as a dual implementation because moa cannot import ipc (import cycle), with a 'convention is the contract' comment (daemon-misc-epoch-2)
- Additive JSON keys only (omitempty) → ADR-0002 immune, no new event types, no schema migration, gui/types untouched; wire-exact pins capture the real HTTP body at stubs, independently recompute sha16, and compare against the journaled receipt (daemon-misc-epoch-2) (moa-chain-epoch-1)
- R-W3: learner_via/curator_via prefs flags route learner/curator through moa.Query via the shared resolveVia(task, prefKey) convention; receipts use R-W1.5 sha16 not R-W2 prompt_sha16; learner parse failure still returns the receipt (request already on the wire) while transport failure carries none; truncation/errors fail-closed before any page rewrite (moa-chain-epoch-1)
- ADR-0003 inv7 reworded with DSF: cadence stays daemon-owned and direct-moa transport creates no model write path (daemon owns all memory writes); GUI timeouts raised to cover worst-case moa chains (DISTILL_READ_TIMEOUT 2100→3300s, CURATE_READ_TIMEOUT 660→1560s) (moa-chain-epoch-1)
- Receipt coverage audit concluded no residual gap: /panel journals before the call with fail-closed assertSlashReceipts, all three review lanes (manual review_diff, auto-land gate, skill gate) journal after the call before consumption via the shared ReviewResult fields; auto-land gate journal failure ⟹ not landing (daemon-misc-epoch-1)
