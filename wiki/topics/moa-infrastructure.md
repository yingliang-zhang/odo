# MoA Client Infrastructure

- R-W1 resilience in `internal/moa/client.go`: bounded retry (max 3 attempts, 200 ms × 2ⁿ with ±50% jitter via `math/rand/v2`, `Retry-After` honored and capped at 30 s); retryable = 429/≥5xx/network/timeouts, 4xx and request-build failures never retry; cancellation skips retry and preserves `errors.Is(err, context.Canceled)`; typed `Error{Status,Class,Message,RetryAfter}` with five classes (repo-wide grep confirmed zero callers on the old error string) (moa-chain-epoch-1)
- Result ledger added to moa `Result`: `InputTokens/StopReason/WallSeconds/TokPerSec` — token fields record the final request, wall time covers the whole logical call; tool-loop `Result` still deliberately drops `Thinking` to preserve /panel behavior (moa-chain-epoch-1)
- R-W1.5 premise correction: the claim that `RequestSHA16`/`RequestBytes` came from R-W1 was false (verified via `git show` + grep) — client-side receipts were built in full; recorded at `post()`'s marshal point (the only place holding wire bytes) under the final-request convention: one receipt per retry chain, escalation receipt points at the final body, error returns carry no receipt (daemon-misc-epoch-2)
- sha16 exists as a 4-line duplicated helper in moa (cannot import ipc due to import cycle) carrying a "convention is the contract" comment; threading is additive `omitempty` JSON keys only — ADR-0002 immune, no new event types, no schema migration, no GUI types change (daemon-misc-epoch-2)
- Receipt audit: every moa call site in `internal/ipc/` journals a receipt before consumption — /panel (bytes journaled pre-call + `assertSlashReceipts` fail-closed), /vision (`image_sha16[]` pre-call), manual review, auto-land gate (journal failure blocks landing), skill gate — no visible⟺logged residual; byte-exact receipts and learner memory-file hashing deferred to R-W1.5 and R-W8 respectively (daemon-misc-epoch-1)
- R-W3 flags `learner_via`/`curator_via` route learner/curator through `moa.Query` (opt-in; absent or `omp` keeps the wrapper byte-identical) via one shared `resolveVia(task, prefKey)` convention; curator truncation/errors fail-closed before any page rewrite; learner parse failure still returns the receipt while transport failure carries none; GUI timeouts raised (DISTILL 2100→3300 s, CURATE 660→1560 s) from the measured 1446 s worst-case moa chain (moa-chain-epoch-1)
- Wire-exact test discipline: stubs capture the real HTTP body and tests independently recompute sha16 against journaled receipts — `TestRequestReceiptWireExact` covers single-shot/retry-chain byte-identity/escalation→final/tool-loop→final/no-receipt-on-error; `TestPanelTruncationFlagged` proves the panel receipt equals the post-escalation final body, not the truncated first body (daemon-misc-epoch-2)
