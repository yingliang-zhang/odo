# Worktree, Workstream & Run Lifecycle

- `retireRun` targets the diff's OWN run by `worktreePath` match; the `byConv` binding is only a fallback and is reaped only when it points at the closed run — reviewing older diffs no longer kills newer runs' worktrees or in-flight verify (main-epoch-28)
- Reject-path rescue replaces lifecycle change: before worktree retirement (accept and reject share the path), snapshot the full delta and write `.odo/diffs/<run>-rescue.diff` only when it differs from the archived patch; archived bytes are never rewritten and the sweeper exemption keeps `.odo/diffs` append-only (main-epoch-35, main-epoch-36)
- delete_workstream vs bootstrap atomicity: the `deletingWs` flag is hoisted unconditionally before the conversation lookup and bootstrap's create section moved under the same lock — the conversationless lane can no longer bootstrap-create under a deleted workstream (main-epoch-42)
- `handleDeleteWorkstream` checks daemon in-memory active state (run/distill/slash/panel/loop/autoPending) then journal-derived loop activity before the SQL delete; the residual sub-second window was accepted as user self-inflicted with the store's pending-diff check as backstop — full atomicity needs deletion inside the run state machine (main-epoch-38)
- Accept dirty-path guards: both apply sites refuse when patch-own paths carry staged/unstaged/untracked content (`git.DirtyPaths`); the refusal is NOT wrapped as `errBaseStale` (that would burn a revise round against what needs human triage); `ProbeAlreadyLanded` runs first so unstaged identical edits still land via bookkeeping (main-epoch-28)
- Staged-only divergence is refused before adjudication via `git.IndexEditsBeyondHEAD` (index vs HEAD stage-0 compare) — closes `git add` silently clobbering a divergent index (main-epoch-32)
- Atomic run-start guard: one struct field + guard helpers wired at every start site (send tail, slash routes, auto fire/arm, preview slash slot, distill entry, loop start) closes run-start duplication (main-epoch-39)
- Daemon-side liveness drain: `runLivenessDrain` is mounted in `NewServer` (2s default interval, atomic toggle, `startRig` dark-launch precedent) so loops genuinely continue with the GUI closed for agent-run phases (main-epoch-14)
- Revise worktree discipline: repair prompts carry a WORKTREE (canonical) section with the absolute path and the worktree is created before prompt assembly; `drainRun` journals `review_action{revise_product_missing}` + recovery advisory when a revise run finishes clean-and-empty instead of wedging silently (incidents #81/#83); standing rule — the run's own bound worktree is the only canonical checkout (bug-fix-epoch-12, bug-fix-epoch-13)
- Workstream name dedupe: `migrateV4` dedupes fossil duplicate names (winner keeps the name, loser gets `-dup-<id>`) plus a partial unique index on `status='active'`; `CreateOrGet` re-reads the winner row on constraint conflict; the index was deliberately excluded from unconditional v1 DDL because legacy DBs need dedupe first (main-epoch-38)
