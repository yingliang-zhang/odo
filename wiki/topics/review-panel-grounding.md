# Review Panels & MoA Grounding

- Exactly one grounded reviewer leg per fan-out (review panels and loop audits), and its verdict weighs identically to every other leg. (bug-fix-epoch-18)
- Model-visible is journal-visible, including refusals: every grounded-leg read attempt lands in tool_calls, appended before the tool output returns to the model, making citing-without-calling test-detectable. (bug-fix-epoch-18)
- Grounded scope is the one-hop import neighborhood computed daemon-side and LLM-free (touched paths, same-directory Go siblings, repo files importing touched packages, repo-internal imports), hashed as scope_sha16; computation failure degrades to touched-only with a journaled scope_truncated marker (fail-visible). (bug-fix-epoch-18)
- Gate-source grounding fails closed: with grounded_review_required gate_sources (default), a degraded grounded leg on a gate-source diff is Infra and fails the round. (bug-fix-epoch-18)
- Tool-budget exhaustion still owes a verdict (journaled tool_budget_exhausted; a missing verdict token degrades review to needs_fixes and audit to parse_error), and an empty scope is legal rather than an init failure. (bug-fix-epoch-18)
- Tool-loop exhaustion marks a grounded leg Infra regardless of posture, so panelInfraLeg parks the round blocked-pending (recoverable) instead of counting a synthesized needs_fixes as real dissent. (bug-fix-epoch-27)
- The grounded round cap went 16 to 40 as a parameterized Server field active by default (resolver: field, then ODO_GROUNDED_TOOL_ROUNDS env, then grounded_tool_rounds pref, then 40, clamped at ceiling) — a 16 default would ship the tool-loop incident unfixed; env/prefs are the escape hatch, not activation. (bug-fix-epoch-38)
- A wall-clock interlock scales the grounded leg's outer deadline by rounds/16 so the typed infra death stays round capacity rather than a misleading timeout; worst case is ~78min/leg, revertible via env or prefs without redeploy. (bug-fix-epoch-38)
- Fail-visible round accounting: ToolRoundsUsed is journaled on every grounded leg row; round-cap deaths carry call names/args and are visually distinct from fail-soft tool_budget_exhausted; groundedToolCallsCap was raised 64 to 96 so the audit trail survives 40 rounds. (bug-fix-epoch-38)
- defaultToolRounds stays 16 so callers passing 0 keep old semantics (pinned), and the round-cap ladder must track the diff-size ladder (32K to 256K) — otherwise grounded legs die tool-loop-exhausted on healthy diffs that ungrounded legs accept (the K3 incident: five grounded-leg deaths on a 16-round cap). (bug-fix-epoch-38)
- Quad-blind design review (4/4 NEEDS_FIXES on v1) consolidates into a lock v2 implemented exactly as locked — no additions, no omissions — with consensus math, verdict semantics, Infra classification, the revise ladder, and the 256KB fail-soft byte budget explicitly untouched. (bug-fix-epoch-38)
- The D6 design diversity gate requires 2+ successful legs from 2+ distinct model families; refusal journals auto_gate refused_diversity, skips spawn, and leaves the lock pending for the human gate — the task is never skipped. (bug-fix-epoch-21)
- Model family derives from the bare model id (provider suffix stripped, basename prefix before the first hyphen), not the provider label — the same model under two labels is one family; diversity is computed over the good set only, with scrubbed endpoints recorded honestly. (bug-fix-epoch-21)
- Single-family panels have zero auto-reject capacity — every divergent verdict minority-suspends, fail-closed and visible. (bug-fix-epoch-17)
- Panel claims are triaged against source before action: a valid-but-unreachable contract hole gets fixed (sameAutoDistillList consume semantics), while prop-stability and leaf-symlink objections were rejected with evidence. (main-epoch-33)
- Finding identity is structural: fingerprint v4 = sha16 over normed file, symbol, category (plus optional rule), with title/evidence demoted to mutable description; per-leg dedup precedes cross-leg folding, and leg_ids align to the journaled legs fan-out for falsifiability. (bug-fix-epoch-16)
- The Server owns one shared MoA client (a single NewClientFromEnv funnel) with concurrency-cap pin tests. (main-epoch-16)
- Token-usage ledger rows are journaled idempotently for all non-loop runs at the drain seam, with verify_ms recorded fail-soft on verify outcomes. (bug-fix-epoch-30)
- Escalation accounting records the re-paid prompt cost of abandoned requests on each bump (Escalation.InputTokens). (main-epoch-23)
