# Path Containment & Security

- The canonical resolved projectRoot is the final trust anchor: the three-arg guard verifies the resolved dir stays inside the project AND rejects symlinks at the root nodes themselves (.odo, wiki, wiki/topics); the write side carries the same guard as reads, and stale-file cleanup (os.Remove) is pre-guarded. (main-epoch-34)
- Containment scope is project-side paths only - global ~/.odo dotfiles (user.md, pins) are outside the threat model because restricting them would break legitimate dotfiles symlinks; wiki/ is git-committable so it is in scope. (main-epoch-30)
- Containment violations degrade to vanished/absent semantics - no new error faces. (main-epoch-30)
- /preview SSRF defense is Go-side per-hop redirect validation plus final-URL capture (unreachable hosts fail-fast at probe), and an in-process loopback-only filtering proxy env-injected into the Playwright child (off-loopback requests logged and denied before dial, --proxy-server fallback); JS/meta-refresh redirects remain an accepted, documented v1 boundary. (main-epoch-32)
- /preview runs the lockfile-pinned Playwright version (1.62.1) in an explicit setup phase - never unpinned playwright@^1 remote code; the 204-to-HEAD + 302-to-GET split-request bypass is closed because capture runs in-process. (main-epoch-34)
- Reads enforce size caps DURING the read, before allocation - a capped reader replaces os.Stat, unbounded os.ReadFile, then post-hoc length check for loop files. (main-epoch-42)
- readLoopTaskFile uses an os.Stat size pre-check with the read anchored at resolvedRoot - closing both symlink escape and read-then-limit memory pressure. (main-epoch-38)
- Skill paths resolve the whole directory chain through guardedBase (a symlinked .odo/skills degrades the project skill scope to absent); handleDeleteSkill gained guardProjectWritePath (update already had it, delete did not); scans enforce a 64KB per-file limit - oversized files are skipped entirely and one large skill no longer blocks smaller relevant ones (break becomes continue). (main-epoch-38)
- Loop artifacts (findings, design_lock) fail closed at BOTH read sites via loopArtifactBody: guarded containment plus <field>_sha16 comparison - tampered, escaped, or symlinked artifacts are rejected. (main-epoch-38)
- Accept rollback refuses to destroy user work: git.DirtyPaths guards both apply sites - patch-own paths carrying staged/unstaged/untracked content refuse with named paths and the diff stays pending for clean-and-retry; the refusal is deliberately NOT wrapped as errBaseStale (that would burn ~8.5-minute auto-revise rounds regenerating a patch that hits the same refusal - user dirt needs human triage); M20 identical-content rescue still runs before the refusal. (main-epoch-28)
- Staged-only edits are detected by git.IndexEditsBeyondHEAD (index vs HEAD stage-0 compare) with a unified refusal before adjudication - git add can no longer clobber a divergent index. (main-epoch-32)
- alreadyLanded detection uses pre-commit per-file byte comparison via a temp-index post-image vs worktree hash-object - whole-file CommitPaths would absorb stray edits. (main-epoch-30)
- Supply-chain surfaces (package.json/lockfiles, CI workflows) stay hard-blocked: a one-line lockfile dependency change is an RCE vector diff review structurally cannot judge, and the path predicate is a SSOT shared by gate and risk classifier. (main-epoch-24)
- AGENTS.md memory reads go through readWithinDir containment (escape means absent) with Lstat symlink refusal on daemon-owned writes. (main-epoch-32)
- A leaf-only Lstat refusal of an intermediate .odo symlink was ruled worthless - if .odo is a planted symlink the journal, db, and socket are all already escaped (full compromise); the root-anchor guard is the real defense. (main-epoch-33)
- Deliberately unguarded by threat-model ruling: diff PathOnDisk (adapter/test-generated, outside the committable surface) and vision attachments (user-supplied explicit paths). (main-epoch-34)
- Risk classifiers tokenize structurally: FieldsFunc punctuation tokenization catches rm -r -f, rm -Rf, multi-space, and --recursive --force; env-dump forms hit credential_probe without suffix pairing. (main-epoch-23)
