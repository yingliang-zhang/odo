# Security Containment & Sandbox

- `guardProjectWritePath` three-arg guard: canonical `projectRoot` is the final trust anchor; symlinks rejected at root nodes (`.odo`, `wiki`, `wiki/topics`) and any intermediate; write side guarded identically to reads (main-epoch-34)
- Containment scope: project-side paths and git-committable surfaces are guarded; global `~/.odo` (user dotfiles/symlinks) and user-supplied explicit paths (vision attachments, adapter `PathOnDisk`) are deliberately outside the threat model; escapes degrade to `vanished`/`absent`, never new error faces (main-epoch-30)
- Skill chain resolved through `guardedBase` — a symlinked `.odo`/`.odo/skills` degrades the whole project skill scope to absent; `handleDeleteSkill` gained the same guard update already had; skill scan enforces 64KB/file with `break→continue` so large skills don't block smaller ones (main-epoch-38)
- /preview defense: Go-side per-hop redirect validation + final-URL capture (`final_url` audit field), plus an in-process loopback-only filtering proxy env-injected into the Playwright child; JS/meta-refresh redirects remain an accepted, documented v1 boundary; playwright pinned to lockfile 1.62.1 with explicit setup phase (main-epoch-30)
- /preview external-redirect bypass closed by the loopback proxy: off-loopback requests are logged and denied before dial, race-free (204-to-HEAD/302-to-GET bypass eliminated) (main-epoch-32)
- Staged-only edits no longer silently clobbered: `git.IndexEditsBeyondHEAD` compares real index vs HEAD stage-0; unified refusal before adjudication leaves the diff pending (main-epoch-32)
- Loop artifacts fail closed: `loopArtifactBody` guarded containment + `<field>_sha16` comparison on findings/design_lock reads; loop file read is bounded by size pre-check + capped reader that enforces the limit during read, before allocation (main-epoch-38)
- Verify sandbox runs under a scratch HOME with credential-scrubbed allowlist (fail-closed on isolation); Go telemetry dir is pinned under `$TMPDIR` so its async writes never race `t.TempDir` cleanup (main-epoch-27)
- Verify sandbox shares the scratch-HOME + arming contract with tests: `TestAutoLandStartedRowsAbsentBeforeSpend` lacked both and failed only on machines without a configured review — isolation+arming is a documented convention all pipeline tests must follow (main-epoch-25)
- Risk classifier hardening: env-dump token detection (`os.Environ(` without suffix pairing), punctuation-tokenized split-flag rm (`rm -r -f`, `rm -Rf`), SSOT CI-workflow supply-chain predicate shared by gate and classifier; CJK prompt tokens estimated 1/rune (len/4 underestimated ~3×) (main-epoch-23)
- Loop file unbounded-read window closed: capped reader enforces the size limit during read, replacing post-hoc length checks (main-epoch-42)
