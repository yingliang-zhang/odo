# Path Containment & Security Guards

- Canonical projectRoot is the final trust anchor: guardProjectWritePath verifies the resolved dir stays inside the project and rejects symlinks at the root nodes themselves (.odo, wiki, wiki/topics), with the same guard on the write side as reads (main-epoch-34)
- Skill directory resolution: the dir chain resolves through guardedBase so a symlinked .odo or .odo/skills degrades the whole project skill scope to absent; handleDeleteSkill gained guardProjectWritePath (update already had it, delete did not) (main-epoch-38)
- Skill content scans enforce a 64KB per-file limit (oversized file skipped entirely) and injection 'break → continue' so a large skill no longer silently blocks smaller relevant ones (main-epoch-38)
- AGENTS.md generation is protected: reads of project memory.md/pins.md go through readWithinDir (escape → absent semantics, no new error faces) and daemon-owned writes Lstat-refuse symlinks (main-epoch-32)
- Containment scope is deliberately project-side only: global ~/.odo files (user.md, pins) are excluded from the threat model because restriction would break legitimate dotfiles symlinks; wiki/ is in scope because it is committable (main-epoch-30)
- /preview hardening evolved in two steps — per-hop redirect validation with final-URL capture and audit field, then an in-process loopback-only filtering proxy env-injected into the Playwright child denying off-loopback requests before dial; JS/meta-refresh redirects remain an accepted, documented v1 boundary (main-epoch-32)
- Playwright for /preview is pinned to lockfile version 1.62.1 with an explicit setup phase and offline-resolution verification, replacing playwright@^1 unpinned remote code (main-epoch-34)
- Loop artifact bodies (findings/design_lock) go through loopArtifactBody: guarded containment plus per-field sha16 comparison; tampered/escaped/symlinked artifacts fail closed at both read sites (main-epoch-38)
- Risk classifier coverage added: os.Environ/dump-form tokens hit credential_probe; FieldsFunc punctuation tokenization catches split rm flags (-r -f, -Rf, --recursive --force); CI workflow paths (.github/workflows/, .gitlab-ci.yml) share a single SSOT predicate between the gate and the classifier (main-epoch-23)
- Diff PathOnDisk (adapter/test-generated) and vision attachments (user-supplied explicit paths) were deliberately left unguarded as out of the committable threat model — explicit non-goals, recorded so future audits don't re-flag them (main-epoch-34)
