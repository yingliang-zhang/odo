# GUI Architecture & Tech Debt

- Reviewed structural gaps (benchmarked against real Hermes Desktop): monolithic 2288-line App.tsx state, boxed-card visual language, and six product concepts crammed into a 380px tab strip; the Phase-1 perf items (windowing, rAF resize, sidebar animation) are since fixed (main-epoch-42)
- Visual incoherence root cause: gui/src/styles/app.css:56 mixes Apple HIG radii, the Multica type scale, Hermes stroke/shadow, and Apple motion, while tailwind.css:5 is mid-migration with legacy overrides winning the cascade (main-epoch-42)
- Recommended GUI order: perf fixes first (done), then split durable pages (Wiki/Memory/Skills/Ledger) from working panes (Changes/Review), then a single design contract — chat column 760-840px, flat agent replies, fewer badges (main-epoch-42)
- Debt watch: the main bundle is 625.18 kB, over the 500 kB build warning, with a lazy split for cold start unscheduled, and React act(...) warning noise in vitest remains unaddressed (main-epoch-42)
- Two-step accept is intentional: the first .btn-accept click opens an inline commit-message editor prefilled 'odo: accept diff #N' and the confirm sends accept_diff; accept badges appear only on resolve while reject stays single-step — tests must follow the full two-step flow (main-epoch-5)
- GUI forward-compat: unknown memory layers fall through to a generic chip, so new daemon-side layers never break the panel (types.ts layer comment documents this contract) (main-epoch-42)
- LoopChip/deriveLoopStates is a pure TS mirror of the Go loop fold (loop id = journal seq; loop_budget_exceeded folds to suspended; notifiedKinds dedups the four terminal kinds journaled via loop_ctl) so the chip re-derives entirely from the event stream while loops run daemon-side (main-epoch-4)
- Slash autocomplete: registry entries carry descriptions, '/' opens the full list immediately, Up/Down + Tab/Enter + Esc drive selection, accepted commands render as a token overlay, and the menu-open condition allows cmd plus one subcommand word (main-epoch-4)
- Cross-project leakage is structurally impossible: the Rust bridge opens a fresh connection per call to the socket under the active projectRoot, a busy conversation rejects stray sends, and applyBootstrap fully replaces the event list on project switch — a '/panel in the wrong project' sighting was workstream-name ambiguity, fixed by rendering project and workstream in the TopBar (main-epoch-7)
- Epoch-32 GUI batch landed: resize grip z-0 to z-20 with a 4px wider hit area, six panels wrapped in memo(...), aggregate setState given prev-bail comparators, and unstable inline callbacks moved to useCallback (main-epoch-32)
