# Path Containment & Security

- guardProjectWritePath anchors on the canonical projectRoot, verifies the resolved dir stays inside the project, and rejects symlinked root nodes (.odo, wiki, wiki/topics) on BOTH read and write sides; violations degrade to absent/vanished semantics, never new error faces (main-epoch-34)
- Guard-text drift bit once: epoch-34's branch replacement changed the rejection string from 'refusing to write through symlink' to 'symlinked component' while one replay_test assertion lagged — a deterministic same-bytes re-run reproduced it and a repo-wide grep confirmed that single stale site (main-epoch-35)
- Loop task-file reads enforce the size cap DURING the read with a capped reader (replacing Stat then unbounded ReadFile then post-hoc length check), so file growth inside the check window cannot force a full allocation before the cap applies (main-epoch-42)
- Loop artifacts (findings, design_lock) pass through loopArtifactBody — guarded containment plus <field>_sha16 comparison — so tampered, escaped, or symlinked artifacts fail closed at both read sites (main-epoch-38)
- /preview containment: an in-process loopback-only filtering proxy is env-injected into the Playwright child (off-loopback requests denied before dial), per-hop redirect validation with final-URL capture, and the browser pinned to lockfile playwright@1.62.1; JS/meta-refresh redirects remain a documented v1 boundary (main-epoch-32)
- AGENTS.md generation reads layer files through readWithinDir and refuses symlinked writes on daemon-owned files — closing the prompt-injection channel where a symlinked memory.md/pins.md could redirect reads outside the project (main-epoch-32)
- Threat-model boundaries are recorded: project-side committable paths (including wiki/) are in scope; global ~/.odo files stay unguarded (legitimate dotfile symlinks); diff PathOnDisk and vision attachments are deliberately unguarded as outside the committable threat model (main-epoch-30)
- Supply-chain paths stay hard-blocked alongside memory paths: a one-line lockfile/manifest change is an RCE vector that diff review structurally cannot judge (main-epoch-24)
- Risk classifier hardening: os.Environ dump forms hit credential_probe, split rm flags (rm -r -f, rm -Rf, '--recursive --force') tokenize correctly via FieldsFunc, and CI workflow edits classify through the shared autoLandSupplyChainPath SSOT predicate (.github/workflows/, .gitlab-ci.yml) (main-epoch-23)
