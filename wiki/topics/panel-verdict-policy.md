# Panel Review & Verdict Policy

- Settlement doctrine: divergent verdicts (including `panel_mixed`) enter the repair ladder instead of instant auto-reject; at the round cap a strict majority (>½) decides land vs reject, else suspend for human (main-epoch-19)
- Three-round rule: rounds 1–2 require unanimous accept (fail-closed veto); round 3 is terminal and falls back to the majority valve (≥2/3 accept, zero reject/infra/truncated, gate-source permanently excluded); implemented as `settleMaxReviseRounds 3→2` (main-epoch-21, main-epoch-22)
- Any truncated leg invalidates the majority valve and abstains from cap counting (fail-closed); relaxing this needs an explicit user decision (main-epoch-20, main-epoch-21)
- D7 verdict policy: exactly 1 reject leg, or ≥2 rejects all from one model family, suspends via `auto_land_blocked{panel_minority_reject}` (diff stays pending, inbox advisory); only ≥2 rejects from ≥2 distinct families auto-reject via M20 mechanics (bug-fix-epoch-17)
- Minority re-panel is bounded at `repanel_count=2` by a journal-derived fail-closed ledger (count read failure returns max = parked), then the diff parks human-only (bug-fix-epoch-17)
- Model family is derived from the bare model id via exported `modelspec.Family` (provider tag stripped, lowercase-folded); same model under two provider labels = same family (bug-fix-epoch-17, bug-fix-epoch-21)
- D6 design-MoA diversity gate: the auto design gate requires ≥2 successful legs from ≥2 distinct model families; refusal journals `auto_gate:"refused_diversity"`, skips spawn, and leaves the design lock pending for the human gate — manual `/design_moa` path unchanged (bug-fix-epoch-21, bug-fix-epoch-22)
- D2 grounded reviewer leg: exactly one grounded leg per fan-out with identical verdict weight; scope = LLM-free one-hop import neighborhood (touched ∪ same-dir ∪ importers ∪ imports, hashed `scope_sha16`); budgets 8 rounds/64KB-per-read/256KB-total; every read attempt journaled including refusals; a degraded grounded leg on a gate-source diff fails closed to Infra (bug-fix-epoch-18)
- D1 gate policy: two tiers — Tier-0 human-only (`gatepolicy.go`, `gate_manifest.json`, editing IS an exemption grant) and Tier-1 prefixes (ipc/store/git/moa/adapter + root main.go); tracked manifest with Tier-0 sha16s + startup drift latch that refuses autoLand/loopFix/valve as `gate_policy_drift`; human-only `odo gate re-pin` recomputes hashes and never commits (bug-fix-epoch-14)
- Diffs are goal-anchored at creation (schema v3 `diffs.goal`, written by `drainRun`); recover/`review_diff`/loop-seed/revise read the stored goal — this killed the anchor bug where the review objective was scanned from the session's last user message and caused #34's wrongful rejection (main-epoch-17, main-epoch-18, main-epoch-20)
- Truncated responses are forced to `needs_fixes` at `reviewVerdict` construction, so downstream vote counting can rely on it (pinned by dedicated test) (main-epoch-18, main-epoch-20)
- Single-judge configs: the panel is never armed; a once-per-daemon-lifetime `auto_land_blocked{single_judge_panel}` advisory fires, and the check is ordered after run-state evidence so an errored N=1 run doesn't burn the quota (main-epoch-15, main-epoch-18)
- Panel legs, `reviewWithModel`, `/vision`, and `/preview` legs all run under `WithTimeout(legTimeout)` outer deadlines — unbounded legs were a found-and-fixed defect class (main-epoch-15)
- Server-level shared moa client with a concurrency cap replaced per-call `NewClientFromEnv` (main-epoch-16)
- Panel consolidator intentionally stays status quo: divergence is the product; any future merge must be a lazy post-fan-out pass (`agent_text{panel_merge}`), never inline in the fan-out path (main-epoch-14)
- Panel stub verdict format is exactly `"ACCEPT\n<reason>"`; `"VERDICT: ACCEPT"` does not parse and spuriously spawns the revise ladder in tests (bug-fix-epoch-14)
