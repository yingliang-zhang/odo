# Path Security & Symlink Containment

- Canonical `projectRoot` is the final trust anchor: the three-arg guard verifies the resolved dir stays inside the project and rejects symlinks at the root nodes themselves (`.odo`, `wiki`, `wiki/topics`), with the identical guard on the write side (main-epoch-34, main-epoch-35)
- AGENTS.md generation reads memory/pins through `readWithinDir` (escape degrades to absent) and refuses symlinked daemon-owned files on write — the P0 prompt-injection path is closed (main-epoch-32)
- Containment scope is project-side committable surfaces only (wiki included, since odo commits it); global `~/.odo` files are excluded because real users legitimately symlink dotfiles (main-epoch-30)
- Explicit non-goals stay unguarded: diff `PathOnDisk` (adapter/test-generated archive surface) and vision attachments (user-supplied explicit paths) (main-epoch-34)
- Skill chain is resolved through `guardedBase` (a symlinked `.odo/skills` degrades the whole project skill scope to absent); `handleDeleteSkill` gained the same guard update already had; skill scan enforces a 64KB per-file cap with continue-not-break so an oversized skill can't block smaller relevant ones (main-epoch-38)
- Bounded reads: `readWithinDir` was replaced by a capped reader that enforces the size limit during the read (before allocation), and `handleReadFile`'s >512KiB branch streams via `os.Open` + `io.LimitReader(cap+1)` instead of whole-file reads (main-epoch-28, main-epoch-42)
- Loop files: `readLoopTaskFile` does an `os.Stat` size pre-check anchored at `resolvedRoot`; `loopArtifactBody` adds guarded containment + `<field>_sha16` comparison so tampered/escaped findings/artifacts fail closed at both read sites (main-epoch-38)
- `/preview` is sandboxed: an in-process loopback-only filtering proxy is env-injected into the Playwright child (off-loopback denied before dial, `--proxy-server` fallback), plus per-hop redirect validation and `final_url` capture; JS/meta-refresh redirects remain a documented v1 boundary (main-epoch-30, main-epoch-32)
- Risk classifiers: `riskEnvDumpTokens` catches `os.Environ(` dump forms without suffix pairing; `riskRmSplit` tokenizes split destructive flags (`rm -r -f`, `rm -Rf`); CI workflow paths share the `autoLandSupplyChainPath` SSOT between gate and classifier (main-epoch-23)
