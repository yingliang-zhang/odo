# Test Infrastructure & Flake Management

- A stale dev server on :1420 is the canonical e2e contamination class: playwright's reuseExistingServer: true re-serves an unpatched main tree, producing uniform failure bursts after an all-green prefix — confirm the port is free (or kill the stale process) before gates (bug-fix-epoch-49)
- Worktree e2e targets its own server via the PLAYWRIGHT_BASE_URL knob in playwright.config, added after a worktree server was forced onto 1421 beside a user-owned 1420 process (bug-fix-epoch-48)
- Run npx/playwright from gui/, never the worktree root: root-level npx hits the global-cache runner alongside the worktree-local install (two versions of @playwright/test) and substring-matches specs with no config (bug-fix-epoch-49)
- Cold-cache vitest first-run failures are timeout-shaped (setup 461s vs warm 13s) and machine-load flakes confine themselves to untouched files — re-run before diagnosing, and write full output to a file because tail-only output loses failure names (bug-fix-epoch-49)
- vitest runs without globals: true, so testing-library does not auto-cleanup between tests in a file — stacked panel instances cause multiple-elements-matched failures; the fix is explicit cleanup() in the affected test files (bug-fix-epoch-54)
- Poll-dependent e2e assertions get POLL = {timeout: 12000} because the 1.5s event-poll cadence under load exceeds the 5s default window; RPC-local assertions stay at default — tagging them would mask mechanism (main-epoch-29)
- Measure-then-assert: live-measured widths supersede doc estimates — settle a frame before reading overflow (a first probe raced the React commit and reported stale arrows) and read CSS values in px because CSSOM drops unit-less values (bug-fix-epoch-52)
- Drag-race fix: drain el.getAnimations().map(a => a.finished) before sampling a grip bounding box — animation objects exist the instant style applies, and an x-stability probe over two rAF frames resolves at the animation's from-position (a false settled) because the compositor has not advanced; a persistent/looping animation would stall a.finished forever (bug-fix-epoch-41)
- Recalibrate the spec, not the component: when a legitimately-added 9th tab makes the strip overflow at the default viewport, the 6-tab-era spec is the defect — verify the component behaves correctly first-hand, then update the test to measured reality (bug-fix-epoch-41)
- e2e mock fidelity is part of the contract: the mock must flip poll-side state on accept/reject or the next poll reverts optimistic status, and arming fail without delayMs leaves no deterministic window between optimistic render and rollback (bug-fix-epoch-49)
- IPC suite acceleration rides production seams (ODO_STUB_SCALE, oneShotPollNs, resolvedIdle) rather than a second convention, with t.Parallel() marked only on stateless pure-fold/table/fixture tests — daemon-lifecycle tests stay serial (bug-fix-epoch-33)
- WINDOW-class tests that interleave with a mid-flight run must pin ODO_STUB_SCALE=1 beside their stub wrapper — at scale 0.15 the stub completes in ~0.45s and real work (git apply + journal) exceeds the window (bug-fix-epoch-34)
- gofmt -l exits 0 even when files are dirty — judge cleanliness by its output, not the exit code (bug-fix-epoch-39)
