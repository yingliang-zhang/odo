# MoA Client Resilience, Wire Receipts, and Design-MoA

- R-W1 moa client: bounded retry (max 3 attempts, 200ms × 2ⁿ ±50% jitter, Retry-After honored capped at 30s) on 429/≥5xx/network/timeout only — client 4xx and caller cancel never retry; typed Error{Status, Class, RetryAfter} replaced the '%d' string; Result ledger InputTokens/StopReason/WallSeconds/TokPerSec additive (moa-chain-epoch-1)
- R-W1.5 receipt semantics (final-request convention): request_sha16/request_bytes computed at the client's post() marshal point (only location seeing wire bytes); a retry chain shares one byte-identical receipt; budget-escalation receipts cover the FINAL body (superseded bodies visible via the Escalations ledger); error legs carry no receipt (matches patch_sha16 absence precedent) (daemon-misc-epoch-1) (daemon-misc-epoch-2)
- moa-side sha16 helper is deliberately duplicated (4 lines) because moa cannot import ipc (cycle) — 'convention is the contract' comment (daemon-misc-epoch-2)
- Escalation.InputTokens now journals the re-paid prompt cost of abandoned requests on each budget bump (main-epoch-23)
- R-W3 routing: learner/curator/distill route through moa.Query behind prefs flags (learner_via/curator_via; design_via for Design-MoA) via one shared resolveVia; absent/'omp'/garbage values fail closed byte-identically to the old wrapper; truncation fails closed; ADR-0003 inv7 reworded so daemon-owned memory writes stay explicit; GUI read timeouts raised from the 1446s worst-case moa chain (moa-chain-epoch-1) (moa-chain-epoch-2)
- Design-MoA (design_via: moa): 3 blind concurrent QueryWithTools legs (models from prefs review:) + one consolidator synthesis Query; a truncated leg is a FAILED leg — text dropped, receipts kept, pipeline degrades to survivors and dies only when all legs fail; truncated or whitespace-only consolidator output fails closed with NO design_lock row (moa-chain-epoch-2) (moa-chain-epoch-3)
- Wire-key decision: response field kept as design_proposals NOT 'proposals' — Response.Proposals is claimed by memory_proposals and encoding/json's dominant-field rule would silently drop both same-named sibling fields on marshal (moa-chain-epoch-3)
- designContextBlock symlink-escape fix mirrors fsToolExecutor.resolve: EvalSymlinks the root once (avoids macOS /var→/private/var false positive), lexical check per file + post-resolve validation (moa-chain-epoch-3)
- /panel has NO consolidator by design — N legs concatenated verbatim by formatPanelResults; the no-4th-model rule applies to review vote counting only, so panel Q&A synthesis wouldn't violate it; implementation drafted but gated on user choosing default-on (reuse orchestrator pref) vs pref-gated (UI-epoch-2)
