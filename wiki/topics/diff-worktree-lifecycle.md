# Diff & Worktree Lifecycle Safety

- Reject deletes the candidate worktree; sole survivor is the append-only `.odo/diffs/*.diff` archive (sweeper-exempt) — recovery precedent: dry-check backup → clean apply → re-apply fix → run affected tests (main-epoch-35)
- `rescueResolvedWorktree` snapshots the full worktree delta before retirement on accept AND reject, writing `<run>-rescue.diff` only when it differs from the archived patch; reviewed patch bytes are never rewritten (main-epoch-36)
- Accept refuses when patch-own paths carry staged/unstaged/untracked content (`git.DirtyPaths` guard at both apply sites) — the old rollback wiped users' uncommitted changes (P0); refusal is NOT wrapped as `errBaseStale` to keep the auto-revise ladder from burning verify cycles (main-epoch-28)
- Identical-content rescue (`ProbeAlreadyLanded` reverse-apply probe) runs before the dirty-path refusal — content already in main settles `already_landed` bookkeeping instead of erroring (main-epoch-8)
- Externally-landed diffs (manual commit + FF merge) hang pending forever with no reconcile channel, pinning their worktree via WorktreeRefs; settle manually via one transaction updating status + `review_action` receipt in daemon-accept shape (main-epoch-8)
- `retireRun` selects the retirement target by matching `worktreePath` against `s.runs` (the diff's own run), not the `byConv` binding — reviewing an older diff no longer kills a newer run's worktree/session (main-epoch-28)
- landWG structural invariant: every run pre-adds a lifetime pin inside one `s.mu` hold in `bindRunLocked`; `sealLandAndReleasePins()` closes admissions and sweeps pins in one critical section; post-seal binds refuse, never hang; pin release is owned solely by drainRun's top defer (bug-fix-epoch-6)
- Boot recovery dedup: `recoverPendingDiffs` skips diffs with terminal verdicts (`auto_land_blocked`≠panel_infra, auto_panel `moa_review`, `auto_revise_round`); breadcrumbs and `panel_infra` still re-fire; journal read failure abandons the whole pass fail-closed (UI-epoch-9)
- delete-vs-bootstrap atomicity: delete hoists the `deletingWs` flag unconditionally before the conversation lookup, and bootstrap's create section moved under the same lock with the flag guard — closes the conversationless-lane race (main-epoch-42)
- `handleDeleteWorkstream` checks daemon in-memory active state (run/distill/slash/panel/loop/autoPending) plus journal-derived loop activity before SQL delete; the residual sub-second race is accepted as user self-inflicted with the store pending-diff check as backstop (main-epoch-38)
- recoverPendingDiffs excludes loop-owned seeds; loop runs recover from their own journal fold (main-epoch-16)
- Overlapping diffs landing sequentially must order by base freshness: land the most-evidenced first (#24 before #22, both heavy on `server.go`), then rebase + re-verify the later one (main-epoch-10)
- Session dirs are deleted at retire but prompt files must NOT be — tests read the original run's prompt as audit ground truth; prompts converge via boot sweep aging only (main-epoch-6)
