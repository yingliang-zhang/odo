# Testing Discipline & Flake Policy

- Classify flakes before acting: a uniform net::ERR_CONNECTION_REFUSED burst with all prior gates green is an environmental webServer death — prove it with a dev-server preflight (up + idle survival, launched exactly as Playwright starts it) and a full quiet-machine re-run, then change nothing (bug-fix-epoch-31)
- Gates must run in the worktree that actually holds the diff — launch worktrees are often clean siblings; verify the staged delta is byte-identical to the archived patch before citing evidence (bug-fix-epoch-31)
- When a re-verify pass is interrupted, re-snapshot byte-identity and cite existing heavy evidence (on-disk logs, prior green runs) instead of re-running expensive gates (bug-fix-epoch-31)
- Verify failures are reproduced faithfully (byte-identical worktree, scratch HOME, filtered env) before any accept — the #39 block was a latent main-branch test defect (missing HOME isolation), not a diff regression (main-epoch-25)
- Non-hermetic tests are the flake root: TestRevertEpoch lacked t.Setenv HOME so its outcome depended on ambient ~/.odo/user.md — passing on dev machines, failing in the verify sandbox (bug-fix-epoch-20)
- A/B proof for environment fixes: inject the exact failing env var and watch the deterministic FAIL flip to PASS after the fix (main-epoch-26)
- Poll-loop assertions get POLL = {timeout: 12_000} per the existing REFRESH convention family — never a second convention; RPC-local assertions deliberately don't get the window, with the scope rule documented in the spec (main-epoch-29)
- Eventual-stability e2e contracts become expect.poll instead of single-shot assertions racing post-commit rAF effects (main-epoch-36)
- Dev mocks must give failures a deterministic window: delayMs is checked before the fail branch so fail+delay holds then rejects; specs pin the window instead of sampling outside it (main-epoch-37)
- Keep-alive panels keep hidden DOM mounted, so page-global getByText assertions must be scoped to the panel container (main-epoch-31)
- Assertions are never weakened: spec changes either restore the daemon wire shape (agent_tool_call + result pairs) or fix structurally unmeasurable targets (display:contents rects), justified inline against the unchanged contract (bug-fix-epoch-28)
- Component bugs beat test plumbing: StrictMode's discarded first pass starving PreviewFilePane's fetch was a real Loading-forever bug, fixed via loadedKeyRef in the component; diagnosis arms mock fixtures in a live browser tab and probes the real DOM to confirm each mechanism (bug-fix-epoch-28)
- WINDOW-class tests (interleaving with a mid-flight run) pin ODO_STUB_SCALE=1 beside their wrapper — a 39-file audit found exactly one missing pin; timing-window tests re-verify in 3 fresh processes, and the fix stays strictly minimal (one env pin, no production code) even when the changeset lives in a sibling dirty worktree rather than the dispatched one (bug-fix-epoch-34)
- Suite acceleration extends one existing seam (resolvedIdle → oneShotPollNs atomic), never a second convention; negative windows stay real (settle's 2s nothing-happened windows can't shrink); t.Parallel only for 44 stateless tests while daemon-lifecycle tests stay serial; in-suite stalls are root-caused as real anomalies, not tolerated (bug-fix-epoch-33)
- Planned behavior shifts adjust tests, not production: the run_usage receipt was kept and sequence-pinned assertions updated (pre-receipt prefix + a dedicated receipt-exists row); racing tests await the completion signal with a deadline poll (bug-fix-epoch-33)
- Dispatcher worktree mismatches recur: sessions attach to clean launch worktrees while the changeset lives in a dirty sibling — verify where the diff actually lives before fixing (bug-fix-epoch-33)
- Byte-pin before refactoring: TestSettleRevisePromptBytes was written and green before the prompt-builder refactor so verbatim paths are provably byte-identical (bug-fix-epoch-29)
- Worktree node_modules needs real npm ci (symlink-to-main passes tsc/vitest but breaks Playwright with dual-instance exceptions); `.odo-verify` parses only the first fallback command, so failing verify scripts must be single-line (bug-fix-epoch-30)
- Test-harness flakes (TempDir teardown failures) are re-verified, never fixed by modifying the test (bug-fix-epoch-30)
- Same-class site audit after every fix: fix one, sweep all siblings (mock bootstrap blast radius, e2e arm-fail-then-sample patterns, autoLand HOME-isolation convention) (main-epoch-37)
