# Testing & Verification Discipline

- Poll-dependent assertions (anything riding the 1.5s event poll loop: journaled bubbles, heartbeat N/M, queue rows, spinner settle) get a 12s POLL timeout - the pre-existing REFRESH convention across sibling specs; RPC-local assertions keep the 5s default; a second convention (test.setTimeout) was refused, and the scope rule is documented in the spec (poll-loop 12s, RPC-local 5s). (main-epoch-29)
- e2e must mirror the daemon wire shape: an orphan agent_tool_result (a 0-call burst) folds into the previous run's collapsed tool-group, so prepend the matching agent_tool_call and wait for the folded card's summary before clicking; and measure the box-generating element - display:contents wrappers (.bubble-mount) have an all-zero rect and can never intersect. (bug-fix-epoch-28)
- mock-invoke evaluates delayMs BEFORE the fail branch so armed failures hold a deterministic window - single-shot sampling outside the window is the rAF-race flake class; fix by pinning the window (delayMs 2500) or switching to expect.poll for eventually-stably-visible contracts, and wait for the bootstrap landing signal before arming failure. (main-epoch-37)
- Test isolation is mandatory - tests reading ambient $HOME are environmental lies: TestAutoLandStartedRowsAbsentBeforeSpend failed only on machines without ~/.odo/prefs.md arming (HOME isolation + review-prefs arming added; the convention is documented at the top of the test file, and 23 of 24 sibling cases already followed it). (main-epoch-25)
- Environment determinism pins: PLAYWRIGHT_BROWSERS_PATH scrubbed via t.Setenv(empty) when the host has an ms-playwright cache (os.Getenv non-empty check makes empty equivalent to unset); GOTELEMETRYDIR pinned under $TMPDIR to kill the go-telemetry async-write TempDir cleanup race (audited for the same defect class in the test that itself ran bare go env with scratch HOME). (main-epoch-26)
- Verify runs under a scratch HOME for credential isolation - the sandbox is env-scrubbing, not chroot: absolute-path reads were always possible, and exporting GOCACHE/GOMODCACHE/GOPATH adds zero exposure versus the pre-P1#11 posture that inherited all of HOME; credential knobs stay off the whitelist. (main-epoch-16)
- go test's default 600s timeout sits below the ipc suite's ~535-575s under load - verify runs with -timeout=14m (15m guard); a failure at almost exactly 600s is the timeout, not a deadlock. (bug-fix-epoch-16)
- verify_failed blocks have repeatedly been false positives from test/environment defects rather than the diff - load flakes, stale assertion text after a contract change (refusing to write through symlink became symlinked component), unhermetic HOME-dependent tests, mock timing-race design flaws, and suite timeouts all masqueraded as regressions; diagnose with a same-bytes reproduction before acting on the block. (main-epoch-35)
- Flake policy: a test-harness flake (TempDir teardown) is re-verified, never modified in the test; the flake did not recur on re-apply. (bug-fix-epoch-30)
- A same-bytes green reproduction means a rerun has zero information gain - manual Accept beats a coin-flip re-block that burns ~8.5 minutes of verify plus a panel per round and can end with a dead accept channel. (main-epoch-29)
- Load-sensitive flakes reproduce only under full-machine load - verify the fix under the exact historical load conditions (e.g., run the targeted Playwright spec concurrently with the 539s Go suite). (main-epoch-36)
- Fix-one-audit-all: after a root-cause fix, sweep every same-class site, not just the reported one (only switch-cache.spec.ts:90 shared the mock's arm-fail-then-single-shot-sample shape; the payload's zero overlapping paths excluded regression via that diff). (main-epoch-37)
- GUI gates must run with cwd = gui/ - from the repo root, vitest collects gui/e2e/*.spec.ts as unit files and npx misses gui/node_modules (hit three times in one epoch). (bug-fix-epoch-29)
- Revise-round discipline: byte-pin the contract green BEFORE the refactor (TestSettleRevisePromptBytes proved the verbatim paths byte-identical), and attribute pre-existing failures by stashing the diff and re-running on the bare base before blaming the change. (bug-fix-epoch-29)
- One new test pin per review/audit finding is the convention (10 findings plus 12 pins, including concurrent-panel, double-consumption race, and spill-tamper cases). (main-epoch-38)
- vitest css:false stubs .css?raw to an empty string - CSS tests read source via node:fs and assert on rule declarations in CSSOM (jsdom does not resolve var()); real pixel values are covered by e2e. (bug-fix-epoch-23)
- Page-global getByText assertions break under keep-alive (hidden panels still match) - scope assertions to the container, with a comment documenting the scoping rule and a repo-wide grep confirming it is the only site. (main-epoch-31)
- Seed long-history e2e through the fixtures seam (one page.evaluate pushing into fx.events): 2.7s versus 48.6s of composer sends, and deterministic; derive assertions from the boot DOM count rather than magic constants so fixture drift cannot break the math. (UI-epoch-12)
- capDetail is tail-biased (ellipsis-earlier-truncated prefix, rune-safe cut, 4KB cap) because --- FAIL lines live at the tail - head-trimming ate them and blinded blind reproductions. (main-epoch-26)
- Full verify output is persisted to .odo/verify/<label>-<ts>.log (1MB tail cap per file, pruned to newest 32; success path too via a verify_log field), with the journal keeping the 4KB capDetail tail plus the pointer appended AFTER capping so it can never be truncated away. (main-epoch-36)
- The gui verify line must run all three gates (tsc --noEmit && vitest run && playwright test --reporter=line) - a missing vitest leg let layout diffs auto-reject twice on no recorded run. (bug-fix-epoch-25)
- .odo-verify parses only the first fallback command - a failing multi-line verify script must be single-line. (bug-fix-epoch-30)
- No repo-wide gofmt re-churn: the project gate is build+vet only; reformatting untouched legacy files is refused even when a new gofmt flags them (and suspected diff-introduced gofmt flags were proven pre-existing by stashing). (main-epoch-36)
- e2e timeouts account for backoff, never sleeps: back-to-back poll-failure arms under mock poll backoff (~25s each) plus the dismissed window exceed a 30s cap under load - bump with test.setTimeout and correct the header comment. (bug-fix-epoch-28)
- Order fixes by expected value: the race with a stable reproducer first, the heaviest new durable semantics (project-level outbox) last. (main-epoch-42)
- Minimal-verify discipline in pipeline tasks: run only focused tests plus build/vet, leave the full suite to pipeline verify, never commit or touch main. (bug-fix-epoch-16)
- An extra fixture commit advances HEAD past d.BaseSHA and the revise_ambiguous freshness ladder fires before the verify gate - fixtures must re-read HEAD as BaseSHA after committing. (main-epoch-13)
