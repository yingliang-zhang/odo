# Workstream Switching Performance and Scroll Pining

- Switch jank root causes: full journal replay per bootstrap (ListEvents from seq 0), daemon global lock held over SQL/file I/O in handlePollEvents/handlePendingCounts, unconditional generateAgentsMD rewrite, zero GUI caching (UI-epoch-8)
- Fixes: stale-while-revalidate per-conversation LRU cache (seq-merge is lossless because the journal is append-only), incremental bootstrap via afterSeq/conversationId, snapshot-in-lock/I/O-outside-lock restructure, generateAgentsMD skips identical writes, optimistic flip with full rollback (workstream nameRef restored via rootFlipped boolean, handleSend in-flight responses guarded by captured cid+root) (UI-epoch-8)
- Switch didn't scroll to bottom: stickRef leaked across sessions because ChatSurface doesn't remount when applyBootstrap wholesale-replaces events; fix resets stick+pill and pins to bottom on conversationId change; the test MUST use unequal history lengths (12 vs 72) or browser scroll-anchoring false-passes (bug-fix-epoch-2)
- Auto-follow semantics: un-stick ONLY on explicit gestures (wheel-up excluding inner ticker scroll, touch pull-up, scrollbar drag) — browser scroll anchoring and content-visibility resolution move scrollTop passively and were misread as user intent; programmatic writes get 250ms suppression; ResizeObserver re-pins invisible growth (UI-epoch-2)
