# GUI Frontend (React/Tauri)

- Keep-alive contract: panels stay mounted for state but refetch on the inactive-to-active transition with draft protection (an active prop drives Wiki/Memory/Ledger/Skills) — and because hidden panels still match, page-global e2e assertions must be scoped to their container. (main-epoch-34)
- Hidden-panel recompute is eliminated by memoizing pipeline state on the last relevant review/memory event seq; App aggregate setState gets a prev-bail comparator (reusing diff_stable) so quiet ticks re-render nothing. (main-epoch-32)
- P1 adoption lock: a typed slots.ts data-slot map (update slots.ts, never inline selectors), table-driven keybinds.ts with a shortcuts panel, an ordered errors.ts summarizer grounded in the Rust bridge format strings, and journal search reusing the existing searchEvents stack and switch path. (bug-fix-epoch-26)
- Tool-result inline diffs gate on looksLikeUnifiedDiff and reuse DiffViewer's exported parseFileSegments — no second parser; the run-group header derives an N-files-changed chip that opens the Changes tab. (bug-fix-epoch-26)
- Failure UX: typed overlays keyed by classification (socket closed, heartbeat timeout, version mismatch, verify infra, panel infra) with leading actions; a reload affordance appears once poll failures reach 20; focusSeq is cleared on jump-land and on conversation/workstream switch; dismissal is keyed by failure class and cleared on reconnect. (bug-fix-epoch-29)
- ContextPanel parks at most ~3 tabs (active plus 2 most-recently-used) via an LRU state machine; editors with unsaved drafts are park-exempt, and restoring a parked tab remounts and refetches. (bug-fix-epoch-27)
- StatusBar overflow: chips never unmount (display toggling only, so status-badge e2e hooks stay live), priority-ranked folding with a +N popover of live values; the row must be flex-1 overflow-hidden so clientWidth is a stable available-width signal — a content-adaptive row self-locks, hiding more and more chips with no rebound. (bug-fix-epoch-23)
- Hidden-chip state uses a dedicated chip-hidden token checked via classList.contains, never className.includes(hidden) — the substring also matches overflow-hidden. (bug-fix-epoch-24)
- Panel overlay hysteresis evaluates docked-equivalent width (chatWidth minus panel.offsetWidth while overlayed) or the panel oscillates docked and overlayed forever; drag math uses offsetWidth (clientWidth excludes the border in Chromium — off-by-one); stored width falls back to default on empty or unparseable values. (bug-fix-epoch-25)
- The booted early-return swallowed the ResizeObserver effect — App renders only a loading div until the daemon connects, so a one-shot ref effect never subscribes; fixed with a callback ref stored via useState. (bug-fix-epoch-25)
- StrictMode double-invoke discipline: PreviewFilePane tracks the fetch key whose content actually landed (resetting on rejection) rather than identity-seen — otherwise the committed second pass skips the cancelled first fetch and the pane is stuck loading forever. (bug-fix-epoch-28)
- The perf gate uses limits of ceil(measured p95 x 3) with a 10ms floor in a separate vitest perf config; violations FAIL rather than warn, an env var regenerates the baseline, and contention-inflated readings must never be regenerated into baseline.json. (bug-fix-epoch-30)
- The theme cascade is three layers at :root (63 --p-* primitives, then semantic tokens re-pointed, then pure var() overrides under data-theme light), with equivalence proven by CSSOM var-hop resolution across both themes. (bug-fix-epoch-30)
- PANEL_CONTRIBUTIONS is the single source for panel ids, titles, icons, and badge derivation; the spec's component field was deliberately omitted as inert metadata under keep-alive/LRU wrapping. (bug-fix-epoch-30)
- Esc handling is a priority registry (overlay, menu, panel, global-cancel) with identity-based disposers; React stopPropagation discipline and Radix capture layers stay untouched. (bug-fix-epoch-30)
- twMerge trap: inside cn merges, text tokens must be escaped as text-[length:var(--text-micro)] or the color-group merge silently drops them. (bug-fix-epoch-22)
- Successful polls clear only poll-failed-prefixed errors; switch/send errors persist until the 10s banner timer — otherwise switch failures were silently rolled back. (main-epoch-38)
- The .odo-verify gui gate must run all three gates (tsc, vitest, playwright) — an omitted vitest leg caused two auto-rejections of otherwise correct code. (bug-fix-epoch-25)
- GUI gates must run with cwd gui/ or vitest collects e2e specs as unit files and npx misses gui/node_modules. (bug-fix-epoch-29)
- Known GUI debt: main JS bundle ~625KB over the 500KB threshold (lazy split unscheduled), no transcript windowing (full-history filter/group/map per event), monolithic 2288-line App.tsx, per-pointermove resize setState, sidebar animation relayouting the transcript, mixed design language in app.css, and six product concepts in a 380px tab strip; recommended order is perf, then durable pages versus working panes, then a single design contract. (main-epoch-42)
