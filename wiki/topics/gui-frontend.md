# GUI Frontend & Interaction

- Keep-alive panels stay mounted with state preserved but refetch on inactive→active transition, with uncommitted drafts protected from overwrite; a per-panel `active` prop drives the contract (main-epoch-34)
- Diffs compare by semantic equality, ChatSurface is memoized with unstable props frozen, and pipeline memo keys on the last relevant review/memory event seq with App aggregate setState prev-bail — a quiet poll tick re-renders nothing (main-epoch-32)
- Statusbar overflow chips never unmount — hidden state is a dedicated chip-hidden token class addressed via data-chip attributes (never className.includes('hidden') substrings), so e2e .status-badge hooks stay live (bug-fix-epoch-25)
- Overflow rows need a stable width signal: content-adaptive rows self-lock (hiding chips shrinks clientWidth, hiding more with no rebound) — the row is flex-1 overflow-hidden so clientWidth reads available width (bug-fix-epoch-23)
- Panel overlay uses a hysteresis state machine evaluating docked-equivalent width (chat − panel offsetWidth) to prevent self-oscillation; offsetWidth (not clientWidth) avoids the border-box off-by-one; stored width falls back to default on empty/unparseable values (bug-fix-epoch-25)
- ContextPanel keeps ~3 tabs mounted (active + 2 MRU) with park-exemption for unsaved drafts; restoring a parked tab remounts and refetches (bug-fix-epoch-27)
- Selector addresses live in a typed slots.ts SLOT map with data-slot attributes (zero existing selectors rewritten), and keybinds are a static typed table driving mod-combo dispatch with palette hints rendering live comboFor() (bug-fix-epoch-26)
- ⌘K journal search debounces 250ms and fans search_events across every project read-only, reusing handleSwitchWorkstream for foreign switches; tool-result inline diffs render behind a looksLikeUnifiedDiff gate reusing DiffViewer's parseFileSegments — no second parser, no new IPC (bug-fix-epoch-26)
- Errors summarize through an ordered pattern→{summary, action} map grounded in the Rust bridge's format! strings; classified errors are sticky with ×-dismiss only, unclassified keep legacy auto-dismiss, and rule order matters (restart-failed precedes generic connect) (bug-fix-epoch-26)
- Failure overlay taxonomy: typed classes (socket closed / heartbeat timeout / version mismatch / verify/panel infra); the reload affordance arms at pollFailures ≥ 20, and dismissal is keyed by failure class and reset on reconnect (bug-fix-epoch-29)
- focusSeq (jump-to-message) is cleared on jump land and on conversation/workstream switch — it previously survived forever and pinned arbitrary groups into the render window on seq collision (bug-fix-epoch-29)
- Esc handling is a priority registry (overlay > menu > panel > global-cancel) with identity-based disposers, replacing App's global querySelector chain (bug-fix-epoch-30)
- Panel registry single-sources tab ids/titles/icons/badges in PANEL_CONTRIBUTIONS; the spec's `component` field was deliberately omitted as inert metadata under keep-alive/LRU wrapping (bug-fix-epoch-30)
- Perf gate: separate vitest config, limits = ceil(measured p95 × 3) with a 10ms floor, FAIL not warn, PERF_UPDATE=1 regenerates baseline — contention-inflated readings must never be baked into baseline.json (bug-fix-epoch-30)
- Theme cascade: three-layer :root (63 --p-* primitives → semantic tokens re-pointed → pure var() light overrides), equivalence proven by 42-point CSSOM var-hop resolution (bug-fix-epoch-30)
- The GUI verify gate runs all three legs (tsc --noEmit && vitest run && playwright) — a gui-scoped .odo-verify omitting vitest caused two false auto-rejections; GUI gates must run with cwd = gui/ (bug-fix-epoch-25)
- Successful polls clear only 'poll failed:'-prefixed errors; switch/send errors persist until the 10s banner timer so switch failures never silently roll back (main-epoch-38)
- Confirmed GUI gaps (audited against the real app): no transcript windowing, monolithic App.tsx state, per-pointermove resize setState, six product concepts in a 380px tab strip, mixed design language in app.css, 625KB main bundle over the 500KB threshold; recommended order is perf fixes, then durable pages vs working panes, then a single design contract with a 760–840px chat column (main-epoch-42)
