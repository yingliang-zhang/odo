# E2E Testing & Flake Doctrine

- Flake triage doctrine: same-bytes reproduction FIRST — if identical patch bytes pass, the block was environmental and rerunning the full gate is negative-information (a coin-flip re-block risk); the manual-unlock precedent chain #42/#48/#49 follows this evidence rule (main-epoch-37)
- The dominant load-flake class is the verify gate running concurrently with idle distill (model calls + wiki commits); the FAIL tail is often log-flood from sweeper/todo test daemons, not the real failure (main-epoch-36)
- rAF-race class: assertions on post-commit-effect visuals (scrollIntoView/scrollBy) must use expect.poll — 'eventually stably visible' is the contract; single-shot expects race frames (main-epoch-36)
- Poll-cadence class: journaled UI (question/answer bubbles, heartbeat N/M, queue rows, panel legs) rides the 1.5s idle poll loop, so those assertions take POLL = {timeout: 12_000} by convention while RPC-local assertions (textarea contents, error banners) keep the 5s default (main-epoch-29)
- Mock determinism: mock-invoke evaluates delayMs BEFORE the fail branch so armed failures hold then reject with a deterministic window; specs arm {delayMs, fail: true} together — the prior order rejected immediately, giving a zero-width window a single-shot sample could never hit (main-epoch-37)
- Switch specs wait for the bootstrapLandings fixture counter (proof the fail/delay knobs were consulted) before arming failure — arming mid-flight raced the mock's fixed 50ms invoke delay and made a CORRECT optimistic rollback look like a product bug (main-epoch-28)
- Keep-alive DOM truth: resolved diffs intentionally still render as hidden record cards, so review-inbox assertions are scoped to the .review-inbox container — a page-global getByText can never reach 0 while the hidden panel exists (main-epoch-31)
- Fixture seeding goes through one page.evaluate with fx.ev/events.push (29 run groups in 2.7s vs 48.6s composer-seeded); composer-driven seeding is reserved for interaction tests (UI-epoch-12)
- Structural changes sweep coupled expectations in the same diff: the settle cap 3-to-2 required five synchronized ledger.spec updates (row counts, round names, badge tallies) with a repo-wide coupling audit (main-epoch-22)
- Ambient-HOME tests are environmental lies: auto-land gating reads prefs.md from process HOME, so tests hermetize with t.Setenv — both TestGetSettings and TestPhantomDiffVerdictBlocksAutoLand went red on main precisely because the M20 defaults/arming flip skipped them (main-epoch-9)
- Rule: fix one flake, audit every same-class site — the switch-cache sweep walked the whole e2e tree for 'arm fail then immediate single-shot sample' and found exactly one affected spec (main-epoch-37)
- Whitespace parity between GUI and daemon slash routing (space-only prefix, tab/newline/NBSP fall through on both sides) is pinned by 17 daemon-mirror unit cases instead of a behavior change (bug-fix-epoch-4)
