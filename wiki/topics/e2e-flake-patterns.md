# E2E Flake Root-Cause Patterns

- Rule: root cause is design-level until proven otherwise, and every fix triggers a same-class repo audit, never a rerun wave (main-epoch-37)
- switch-cache:64 class: dev mock evaluated the `fail` branch before `delayMs`, so armed-fail rejected instantly with no failure window → single-shot sample missed it; fix moved `delayMs` first and arm `{delayMs:2500, fail:true}` — sibling window-pinned test was the counter-evidence (main-epoch-37)
- Poll-window convention: assertions riding the 1.5s event-poll loop get the pre-existing 12s `POLL`/`REFRESH` timeout; RPC-local assertions keep the 5s default; tag only after auditing the full poll-dependent surface (main-epoch-30)
- rAF race class: `scrollIntoView`/`scrollBy` run in post-commit effects, so single-shot visibility assertions race frames → use `expect.poll` (contract: eventually stably visible) — applied to context-panel strip-scroll and review-inbox keep-alive cases (main-epoch-36)
- Keep-alive panels broke page-global text queries: hidden panels stay mounted, so `getByText('Diff #1')` matches resolved cards; scope global assertions to containers (`.review-inbox`) and document the rule (main-epoch-31)
- Verify load flakes: gate verify running concurrently with idle distill (model calls + wiki commits) produces spurious FAILs; the adjudication rule is same-bytes reproduction — identical bytes green ⇒ manual accept (precedents #42, #48, #49), zero information gain from reruns (main-epoch-36)
- capDetail 4KB head truncation ate `--- FAIL` lines, forcing blind reproductions on every `verify_failed`; fixed as rune-safe tail-bias truncation plus full gate output persisted to `.odo/verify/*.log` (1MB tail cap, prune to 32) with the journal pointer appended AFTER capping (main-epoch-26)
- Environment-sensitive tests fail deterministically by machine: `TestPlaywrightBrowsersDir` never scrubbed `PLAYWRIGHT_BROWSERS_PATH` which runVerify exports when a cache exists — `t.Setenv` scrub at test start proved by A/B reproduction (main-epoch-26)
- Dirty-path test isolation: staged vs unstaged user edits and `git stash pop` losing `--index` both caused incident-class failures; fixtures must stage-then-judge and isolated reruns are required before blaming load (main-epoch-28)
- Stale Vite dev servers from other worktrees holding :1420 silently sabotaged two consecutive playwright rounds via `reuseExistingServer:true` — kill squatting servers before any e2e gate; bare root-level `npx playwright` mis-resolves to vitest (bug-fix-epoch-7)
- Port-squatting recurred on round 4 (round-3 worktree's Vite held :1420); stale-server cleanup automation before the playwright gate remains undecided (bug-fix-epoch-8)
- The 600s default `go test` timeout now trips the ~575s ipc suite once boot-fold + drain time is added — distinguish timeout from deadlock by the 600s wall, then rerun with extended `-timeout` (main-epoch-42)
