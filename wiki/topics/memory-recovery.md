# Memory Apply & Crash Recovery

- Boot-time project-level outbox (memory_outbox.go) replays unconsumed apply markers and pin receipts across ALL workstreams in store.Event.ID order, re-running the original planner against the CURRENT file (idempotent rebase) instead of skipping foreign state; wired into NewServer startup (main-epoch-42)
- Explanation-set gating: a memory file hash is writable only when explained by journal after_sha values or outbox receipts (mem/pins_after_sha) — manual edits are neither clobbered nor cause retracted-rule resurrection (main-epoch-42)
- Marker-first journaling: applyResolvedBatch journals the intent marker BEFORE any write, closing the crash window where a batch is applied but never marked; reaffirm is set-to-epoch (not a counter), so journal-first pins with heal-before-RMW closes the double-apply class (main-epoch-39)
- Heal walks ALL stranded markers with per-layer newest-wins claims and must also run on the consumed-refusal path and in the auto-gate sweep — otherwise a distill right after a crash retires stranded markers unhealed (main-epoch-39)
- Idempotent-retry contract at the consumed branch: a retry whose heal actually completes the epoch's work returns Applied:true, while heal no-ops (already persisted / bootstrap-healed / untouchable foreign state) keep rejecting — this reconciles legacy TestUserMemoryIdempotency with the newer crash-window pin (main-epoch-40)
- memMu single-writer leaf lock (independent of s.mu/acceptMu) serializes memory batch and pin application with a journal re-fold under the lock for pending/consumed rechecks — closes double-consumption and cross-workstream last-rename-wins (main-epoch-38)
- Boot journal replayer (superseding per-lane heals): per layer only the NEWEST receipt decides — disk==after is a landed no-op, disk==before restores from the receipt body, true-foreign either entry-merges add-only receipts (heal_merged) or journals heal_conflict with embedded stranded_body, surfaced via pending_counts.stranded_memory_ops and a GUI Resolve(overwrite)/Dismiss banner (bug-fix-epoch-6)
- Legacy pin receipts (empty AfterSHA) are terminal landed boundaries competing by eventID; retraction-as-newest stays authoritative (no resurrection); merged rules emit reaffirmed with epoch=1 rather than fabricated recency (bug-fix-epoch-6)
- AGENTS.md carries only the stable protocol (Project Rules + odo-todo contract); dynamic memory/pins copy blocks were removed so the model sees exactly one receipted copy, and generation skips the write entirely when content is unchanged (main-epoch-38)
- runMemoryLayers returns an error and prompt assembly refuses to assemble a blind prompt on journal read failure — a genuinely blind run is impossible even though the failure-append itself may fail when the journal is dead (main-epoch-15)
