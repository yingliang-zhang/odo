# Verify Gate & Test Infrastructure

- Blocked-verdict diagnosis protocol: confirm archive identity by sha16 recompute, attribute the failure by payload paths, reproduce on the identical bytes; a green same-bytes rerun is a manual-accept signal and a full-suite rerun is negative information (main-epoch-36, main-epoch-35)
- capDetail keeps the tail's END (4KB, rune-safe) so --- FAIL lines survive in journaled block details; full gate output also persists to .odo/verify/<label>-<ts>.log with a 1MB tail cap and prune-to-32, the pointer appended after capping (main-epoch-26, main-epoch-36)
- Verify runs under a scratch HOME for credential isolation; tests must be hermetic with t.Setenv — latent env defects (missing HOME isolation on the arming-gate test, unscrubbed PLAYWRIGHT_BROWSERS_PATH) deterministically blocked diffs #39 and #40 before root-causing (main-epoch-16, main-epoch-25, main-epoch-26)
- GOTELEMETRYDIR is pinned under $TMPDIR for go env subprocesses in verify, eliminating async telemetry-write TempDir cleanup races (main-epoch-26)
- The full Go suite sits near/over the default 10-minute go test timeout in this environment; both a 600.45s cutoff and the D3 verify failure were diagnosed as timeouts, not deadlocks — extended timeouts (14m/25m) are the norm (main-epoch-42, bug-fix-epoch-16, bug-fix-epoch-11)
- E2E flake patterns were fixed at design level: mock fail-branch moved after delayMs (arms a guaranteed failure window), POLL={timeout:12_000} applied to every poll-loop-dependent assertion (5s default dies under the 1.5s idle cadence), expect.poll for rAF-racing scroll assertions, and container-scoped queries where keep-alive keeps hidden panels in the DOM (main-epoch-37, main-epoch-29, main-epoch-36, main-epoch-31)
- The dev mock must stay daemon-faithful: bootstrapLandings counters prove fail/delay knobs were consulted; the inbox filters pending while polls return all; search fixtures join conversation→workstream newest-first (main-epoch-28, main-epoch-31, bug-fix-epoch-26)
- .odo-verify is never auto-created by design — a daemon committing its own verify oracle is exactly what the supply-chain gate must block; a one-time-per-project advisory hooks the verify_unconfigured block with HEAD-commit-state detection and None/Partial/Ready three-state scope semantics (main-epoch-12, main-epoch-13)
- GUI-scoped diffs verify via tsc + vitest + playwright lines in .odo-verify; a gui gate line missing vitest caused two auto-rejections of the U1 diff (#97/#98) until the file was fixed at commit 20f08e4 (bug-fix-epoch-25)
- Instrumentation-first bug attribution: deterministic e2e failures get probe instrumentation before any product change; the switch-cache:64 'app bug' proved to be an arming race in the test, fixed via the landing-signal wait (main-epoch-28)
