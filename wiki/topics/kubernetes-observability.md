# Kubernetes Observability

- Degradation contract, verbatim everywhere: data may be absent, the reason may never be absent — off-by-config means no chip/tab/polling; on-but-broken means visible with per-namespace reason rows; partial availability stays a healthy chip with degraded rows, never a third chip state (bug-fix-epoch-54)
- Empty `k8s_namespace` returns `{available:false, reason:off}` immediately with zero exec; validation is fail-loud and ordered — namespace charset -> `bad_namespace` naming the offending element(s) -> `exec.LookPath` ENOENT — all before any subprocess, plus an N>5 namespace cap (bug-fix-epoch-54)
- Chip polling is visibility-gated because each tick is a kubectl subprocess: `!off && !fold.hidden && docVisible`, consolidated into a single effect where mount and project switches ride the same edge, and re-visibility triggers a one-shot refetch before the 5s cadence resumes (bug-fix-epoch-51)
- Exactly one `k8s_status`/`k8s_batch_status` poller app-wide: state lifted to App through a shared hook with JobsChip as a pure consumer; folded chip + closed tab means zero forks; broken keeps polling for recovery detection (bug-fix-epoch-54)
- kubectl discipline: `get` only; `exec cat` is the only pod-file read verb; `--all-namespaces` forbidden; shared 10s context deadline; `EnrichedEnv`; the multi-ns fan runs per-namespace goroutines under a shared WaitGroup deadline with `Namespaces` in configured order, jobs/pods flat-merged, `Available` true when >=1 ns answers, and per-ns 50-row caps OR'd into `Truncated` (bug-fix-epoch-54)
- stderr is capped at capture time — `StderrPipe()` + `io.ReadAll(io.LimitReader(pipe, 1024))`, never an unbounded buffer or post-hoc slice; a flood only blocks kubectl's write side until the deadline classifies it timeout, and the capped tail rides `K8sStatus.Detail` into the popover (bug-fix-epoch-51)
- Batch status: local-mount `*.json` read priority with per-read pod fallback via the `k8s_job_selector` label query (0 hits -> `pod_not_found`, >1 -> `ambiguous_pod`); `schema_version == 1` gate with visible `schema_mismatch` rows labeled by filename (a mismatched schema's field names are untrustworthy) and bottom-sorted; the daemon computes 90s staleness and ships both raw and derived values (bug-fix-epoch-54)
- The wire mirrors kubectl `get jobs,pods -o json` slices (swap-friendly) with a closed reason set — off | bad_namespace | ENOENT | timeout | auth | unreachable — and KUBECONFIG is scraped from `~/.zshrc` (`ExtractExportFromZshrc`) so execs carry the user's context (bug-fix-epoch-50)
- k8s settings keys round-trip through `update_settings` via non-empty-write branches (they were silently dropped before — read mapped, write missing); because writes are non-empty-only, clearing a namespace/context/selector back to empty still requires hand-editing prefs.md (bug-fix-epoch-53)
- `k8s_status` is never journaled (status poll) while `command_result` is (run artifact) — the journaling line is drawn by artifact-vs-poll semantics (bug-fix-epoch-55)
