# Auto-Land Pipeline & Panel Governance

- Three-round panel rule: rounds 1–2 require unanimous accept (any reject auto-rejects, fail-closed); terminal round 3 lands via majority valve whose only reachable composition is {2 accept, 1 needs_fixes}; a truncated leg invalidates the valve (main-epoch-21)
- Gate-source diffs (protectedGateFiles incl. settle.go/autoland.go) require unanimous panel attestation since the 2026-08-22 doctrine; the majority valve has no attestation power, and human Accept bypasses the gate (main-epoch-22)
- autoLandCheck is three-valued: gate source, new top-level dirs, and net-new assertions downgrade from hard block to panel risk annotation; hard blocks remain only for memory paths (.odo/, wiki/) and supply-chain manifests/lockfiles (UI-epoch-11)
- Execution-layer evidence gate panelVerdictAttestsDiff binds patch_sha16 to the exact landing bytes; rejectProtectedPaths/rejectExecutorPaths deleted in favor of rejectMemoryPaths (UI-epoch-11)
- Memory-path diffs are refused at registration inside drainRun (before InsertDiff) reusing the rejectMemoryPaths SSOT predicate: transcript advisory names paths and points to the distill/commitWiki route, salvage patch kept in .odo/diffs, loop reports run_tainted instead of unsolvable advice (main-epoch-24)
- Narrowing the memory-path hard block was deliberately refused: it protects the "agents never write memory" invariant against prompt-injection → 3-leg correlated failure → persistent memory pollution, and supply-chain lockfile changes are an RCE vector diff review structurally cannot judge (main-epoch-24)
- Terminal states (auto_land_blocked with verify_failed or panel_mixed) are never retried by the daemon; manual Accept is the only unlock — precedents #41, #42, #45, #46, #48, #49 (main-epoch-27) (main-epoch-29) (main-epoch-31) (main-epoch-33) (main-epoch-36) (main-epoch-37)

- Restart recovery of pending diffs dedups against journal verdicts: auto_land_blocked (reason ≠ panel_infra), auto_panel moa_review, and auto_revise_round rows are terminal and skipped; panel_infra deliberately re-fires as its only retry channel; journal read failure abandons the whole pass fail-closed (UI-epoch-9)
