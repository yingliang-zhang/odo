# Test Suite & Flake Management

- Poll-dependent assertions (anything riding the 1.5s event-poll cadence) get an explicit `POLL = { timeout: 12_000 }` window following the existing REFRESH convention family; RPC-local assertions keep the 5s default, and a second convention (e.g. test.setTimeout) is refused (main-epoch-29)
- rAF-racing single-shot assertions become `expect.poll` retries when the contract is eventually-stably-visible (main-epoch-36)
- Entrance animations poison geometry sampling: drain `el.getAnimations().map(a => a.finished)` in the helper before `boundingBox()` — a two-frame x-stability probe falsely settles at the animation's `from` position because the compositor has not advanced (bug-fix-epoch-41)
- Full-suite vitest runs with `--maxWorkers=2` under `.odo-verify` (CLI-only, config untouched, explicitly no `--retry` — that would mask real flakes): 5000ms timeouts that are green in isolation are load-induced, not code faults (bug-fix-epoch-56)
- vitest runs without `globals: true`, so testing-library does NOT auto-cleanup between tests in a file — stacked panel instances cause multiple-elements-matched errors; explicit `cleanup()` is required in affected files (bug-fix-epoch-54)
- Mock fidelity is part of the tested contract: mock-invoke must evaluate `delayMs` before `fail` (else arming fail makes bootstrap reject immediately, leaving no window between optimistic render and rollback), and accept/reject mocks must flip poll-side state or the next poll reverts optimistic status; the same-class audit (fix one, audit all) swept every fail-then-single-shot arming and found only switch-cache affected (main-epoch-37)
- Keep-alive keeps hidden panels in the DOM — page-global `getByText` assertions must be scoped to the active container (`.review-inbox`, `.panel-body > div:not([hidden])`) or they match hidden copies forever (main-epoch-31)
- `go test`'s default 10m timeout panics on the ipc suite (baseline ~507-580s) — gates run `-timeout=20m`; it is a budget issue, not a hang (bug-fix-epoch-55)
- WINDOW-class tests — anything interleaving with a mid-flight run — must pin `ODO_STUB_SCALE=1` beside their stub wrapper; at scale 0.15 the stub sleeps ~0.45s, shorter than the real work (AcceptDiff git apply + journal) between send and first poll (bug-fix-epoch-34)
- React StrictMode double-invokes effects and discards the first pass: fetch effects must track `loadedKeyRef` — the fetchKey whose content has landed, reset on rejection — not identity-seen, or the pane sticks on Loading forever (bug-fix-epoch-28)
- Playwright infrastructure rules: kill any stale `:1420` listener first (`reuseExistingServer: true` would bind a stale tree serving unpatched main), invoke `npx`/playwright from `gui/` never the worktree root (dual @playwright/test instances), and use the `PLAYWRIGHT_BASE_URL` knob so worktree e2e targets its own server (bug-fix-epoch-49)
- Suite acceleration uses existing seams (`ODO_STUB_SCALE`, `oneShotPollNs` on the `resolvedIdle` pattern) and `t.Parallel()` only for stateless tests — daemon-lifecycle tests (real NewServer, SQLite, sockets, `t.Setenv`) stay serial (bug-fix-epoch-33)
