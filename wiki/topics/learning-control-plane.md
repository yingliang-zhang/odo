# Learning Control Plane (D9)

- The D9 design lock ships in waves — W3 observability, W4 lifecycle core, W4.5 suite acceleration, W5 rollback/freeze/stall/never-score — under hard constraints: Go internal/ipc only, settle.go untouched, zero LLM in any gate, planMemoryApply reused not duplicated. (bug-fix-epoch-32)
- Candidates arise only from accepted learner proposals on the autoApplyProposals path when the learning_stages pref is ON, and divert into candidate rows instead of writing memory.md directly; retract deltas stay human-originated. (bug-fix-epoch-32)
- artifact_hash is sha256 over {version, scope, base_sha16, base_source_seq, delta, content} using the same planMemoryApply content replay reads; crash-replay with the same base_source_seq is an idempotent no-op while a new distill head legitimately creates a new candidate. (bug-fix-epoch-32)
- The journal row is written before the jsonl row — backfilling CreatedSeq after the append would break append-only dedupe. (bug-fix-epoch-32)
- All gates are LLM-free: lint (bounds, format, dup-free, retract targets exist, evidence note exists, R2 freeze set) and frozen replay (deterministic criteria a–h; missing inputs mean unverifiable = FAIL, fail-closed). (bug-fix-epoch-32)
- Stage transitions are journaled only — candidate to shadow on all-pass, to dropped on any fail with per-check evidence, shadow to canary gated on 3+ main epochs plus re-pass on the grown slice plus a free slot, with shadow_queued so candidates never stick; stage status is journal-fold only, never stored on the jsonl row. (bug-fix-epoch-32)
- The canary seam is deterministic with zero RNG: learning_canary_fraction pref (default 0.25, ceiling 0.5), interleave ordinal % M == 0 per lane, cohort journaled before the run, steer-continuations inherit the chain's cohort, and canary outcomes are excluded from live rows and baseline. (bug-fix-epoch-32)
- Never-score-own-changes is one shared excludedFromScoring predicate (gate-source, memory-path, learning-plane paths) mirrored into the rules-audit baseline/cohort resolution; live audit keeps the legacy posture for unreadable patches, and fail-closed unknown-to-excluded applies only to frozen replay. (bug-fix-epoch-32)
- R1 rollback is candidate-layer-only (binding user ruling): instant fold project_active to rolled_back with zero memory.md writes; if the candidate's text already landed via the receipted path the fold emits the D4 retract_candidate receipt and the human resolves — the daemon never deletes the memory.md line, and restore is bounded to the candidate's own delta.add. (bug-fix-epoch-36)
- The freeze set is recomputed in two passes within a measure tick (rollback before promotion) to close the same-tick same-text re-entry hole, and freeze-set folding strips the oscillation_guard decoration so production journal rows actually hit the set. (bug-fix-epoch-36)
- Freeze decoration stripping splits on the fixed marker prefix; if the reason format ever changes without syncing the marker, the pinned tests go red — a loud suite, not silent drift. (bug-fix-epoch-36)
- Stall is advisory-only: shadow/canary candidates aging past 12 epochs without promotion-worthy evidence journal learning_stall once per (hash, stage); the daemon never auto-promotes or auto-drops on stall. (bug-fix-epoch-36)
- Evidence, measure, and gate are separated greppably and AST-pinned so no single evidence row can move a stage. (bug-fix-epoch-36)
- Promotion cohorts never score own changes: both paired legs exclude auto rows, other canaries, and scoring-excluded rows (fail-closed), with paired minimums of 10+ human outcomes per leg. (bug-fix-epoch-36)
- The canary-measure promotion arm applies marker-first, converges idempotently, journals hold/drop decisions, and treats stall as advisory-only — verified in place, not only via tests. (bug-fix-epoch-36)
- W3 observability: per-lane learning_episode folds over marker-pinned windows, an append-only .odo/learning/candidates.jsonl store, an odo learning status CLI fold, and a MemoryPanel Learning sub-tab as the first flag surface. (bug-fix-epoch-30)
- The W4 baseline was restored from the diff archive, not main — main had landed only 259 of ~6,700 W4 lines, so wiki/epoch notes claiming W4 fully landed at 8979516 were wrong. (bug-fix-epoch-35)
- W4 tests were migrated to the W5 contract (shadow_queued expectations superseded by shadow-to-canary actuation) rather than duplicated. (bug-fix-epoch-35)
- Fix the code, not the test: the fresh-candidate-stays-shadow checkpoint contract held while the real defect was an under-load re-fire of loop-owned diffs injecting a third diff row (the redrive/recover path is the only injector; input assembly is fully sorted, and the seed's plain AgentDone terminal is not filtered), which corrupted replay verdict/outcome attribution and demoted the age-0 candidate to dropped. (bug-fix-epoch-37)
- Cross-lane window arithmetic relies on Event.CreatedAt from SQLite datetime('now') (UTC, YYYY-MM-DD HH:MM:SS) being lexicographically sortable — no extra parsing. (bug-fix-epoch-35)
- Tests asserting auto-apply writes into memory.md under default preferences were fixed at contract level, consistent with the design lock that autoApplyProposals edits route human-Accept-preferred. (bug-fix-epoch-35)
- Boring stdlib: custom itoa/ageText helpers were deleted in favor of strconv.Itoa. (bug-fix-epoch-35)
- W6 GUI (LearningPanel stage feed, stall-advisory rendering, human accept/retract valves) is deferred by design — the valves stay daemon-side. (bug-fix-epoch-36)
