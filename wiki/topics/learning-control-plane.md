# Learning Control Plane

- Candidates arise only from accepted learner-batch proposals when the `learning_stages:` pref is ON, diverted away from direct memory.md writes; stage status is a journal-fold only, never stored on the jsonl row (bug-fix-epoch-32)
- `artifact_hash` is sha256 over {version, scope, base_sha16, base_source_seq, delta, content}, computed from the same pure `planMemoryApply` function replay uses; crash-replay with the same base_source_seq is an idempotent no-op while a new distill head legitimately yields a new candidate row (bug-fix-epoch-32)
- Lint and frozen-replay gates are LLM-free and deterministic — memoryCap bounds, format regex, dup-free, retract targets exist, R2 freeze-set, double-execution byte-identical — with missing inputs failing closed as `unverifiable` (bug-fix-epoch-32)
- R1 rollback is candidate-layer-only (binding user ruling): instant fold `project_active -> rolled_back`, zero memory.md writes; if the candidate's text landed via the receipted path, the fold emits the existing retract receipt and the human resolves via `apply_memory` / `odo rules retract` — the daemon never deletes memory.md lines, and restore is bounded to the candidate's own delta.add (bug-fix-epoch-36)
- Freeze-set folds must match the production journal shape — `learning_frozen` rows carry decorated strings (`text (oscillation_guard: reason)`), so the fold strips the fixed marker prefix — and the set is recomputed two-pass inside each measure tick (rollback before promotion) to close same-tick same-text re-entry (bug-fix-epoch-36)
- Never-score-own-changes: one shared `excludedFromScoring` predicate excludes gate-source, memory-path, and learning-plane rows from both baseline and promotion cohorts (paired legs requiring >=10 human outcomes each); evidence -> measure -> gate separation is AST-pinned so no single evidence row can move a stage (bug-fix-epoch-36)
- Amendment A1: replay checks f/g are deleted (their counters kept as telemetry) and efficacy moved to canary-side f-prime — liveHarm >= 1 in `learningPromotionVerdict` — with a 3-epoch grace keyed by a new `stage_epoch` field and two drop exits, `efficacy_vacuity` and `canary_starved`, both writing zero freeze-set entries (vacuity is not harm); f-prime's attribution join reuses the same shared predicate as replay-era attribution — single source, pinned by a double-execution fixture (bug-fix-epoch-45)
- The shadow->canary checkpoint must not flip when `learningCanaryFraction() <= 0` — otherwise the seam actuates with canaries disabled (bug-fix-epoch-45)
- Human actuation stays human: `promote --global` is marker-first with zero file I/O (user.md never written; the CLI returns rule lines for the human to add manually); `apply` is the sole `held_for_human` entry mirroring `learningPromoteApply` conventions; voluntary `drop` never feeds freeze (voluntary is not harmful evidence); stall stays advisory-only — never auto-promotes, never auto-drops — epoch-keyed so re-cycled candidates re-advise honestly (bug-fix-epoch-40)
- Loop-owned diffs may re-fire under load, injecting a third diff row whose unfiltered terminal skews replay verdict/outcome attribution and demotes a fresh candidate from shadow to dropped — fixed in code, not the test, with a 100x stress harness proving the mechanism (bug-fix-epoch-37)
- Lock docs are historical records: amendments cross-reference via additive banner lines pointing at the authoritative amendment file; frozen criteria text and Status lines stay byte-identical (bug-fix-epoch-47)
